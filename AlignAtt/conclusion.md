# 实验02 结论：复数互相关关系偏置

**结论（收窄）：** 当前这版复相关偏置（A3：标准内容注意力 + 多时延完整复描述 + 门控 g），在**当前数据（RML2018A cls_dev）和当前训练配置**（Global 基线 patch=8/dim=176/depth=6/heads=4、lr=3e-4、50ep、fp32）下，3 个种子（17/42/2026）**没有稳定提高验证集 OA**：逐种子 A3−A0 = +0.26 / −0.58 / −0.32，平均 −0.21（std 0.43，落在种子噪声范围内）。phase-2 的 +0.26 为种子噪声。按文档 §11 的继续标准（"多个种子收益方向一致"）不满足，故**归档、停止追加训练**。

> 本结论**只**针对这一版实现（复相关描述子 + 小 MLP + 首层注入 + 门控 g）在当前数据/配置下成立；**不**据此推断"该数据不需要此机制"，**也不**推断"物理启发的注意力偏置这一类方法无效"。phase-1 已验证描述子的物理正确性，问题不在实现，而在这一版偏置变体未提供稳定增益。

## 1. 最终结果

Phase-3 多种子（17 / 42 / 2026，各 50 epoch，其余超参完全一致）：

| 配置 | s17 | s42 | s2026 | 均值 | 标准差 |
|---|---|---|---|---|---|
| A0 基线（无关系偏置） | 0.3933 | 0.3837 | 0.3837 | **0.3869** | 0.0056 |
| A3 完整复相关偏置 | 0.3958 | 0.3779 | 0.3804 | **0.3847** | 0.0097 |

逐种子 A3−A0：**+0.26 / −0.58 / −0.32** 点（均值 −0.21，std 0.43）。仅 seed 17 为正，恰是 phase-2 筛选所用种子——说明 phase-2 的 +0.26 点是**种子噪声**，非机制收益。

## 2. Phase-2 筛选回顾（seed 17）

| 配置 | OA | vs A0 |
|---|---|---|
| A0 基线 | 0.3933 | — |
| A1 零延迟相关偏置 | 0.3753 | −1.80 |

A1<A2<A3 的单调方向曾支持 H2/H3，但 A3 的收益经 3 种子检验后不成立。A4 低于基线排除了"额外上下文/参数"带来的伪收益解释。

## 3. 关于两条"完全相同"的最优值

排查中发现的巧合，已确认**非 bug**：

- `a0_global_s42` 与 `a0_global_s2026` 的最优 OA 完全相同 = 0.383654 = **1197/3120**，但两个 run 的 metadata 种子正确（42 / 2026）、逐 epoch 轨迹确实不同（首 3 epoch 0.100/0.177/0.227 vs 0.131/0.191/0.249；最优 epoch 29 vs 24）。二者只是在整数化的 val 正确数上撞到同一个峰值。
- `a3_full_s2026`（0.380449）与 `a2_magnitude_s17`（0.380449）同理 = 1187/3120，不同配置不同种子撞到同一整数峰值。

原因：val 集固定 3120 样本，OA = 正确数/3120 是整数化量；该基线各种子峰值都收敛到 0.38 附近的窄带，整数化后偶发重合。轨迹和种子均验证无误，不影响结论。

## 4. 未做 / 后续可选（归档，不再继续）

- A5（打乱关系配对对照）、A6（纯关系/去掉 QK 诊断）未跑。由于 A3 未提供稳定增益，A5/A6 的诊断价值已很低（判断"配对正确性是否重要"的前提——机制已见稳定收益——不满足），不再启动。
- R=32/64 长上下文消融同样不再继续。
- 复相关描述子本身在 phase-1 已验证物理正确（已知延迟/相位能恢复 arg(ρ)=−φ）；问题不在实现，而是这一版"描述子→MLP→偏置"在当前配置下未提供稳定增益。

## 5. 结论范围与启示

- Global 基线（patch=8, dim=176, depth=6, heads=4）在 RML2018A 上的峰值 OA 稳定在 **0.383–0.393** 窄带，跨种子可复现，作为对照基线是可靠的。
- 本实验**只排除**：这一版复相关偏置 + 当前训练配置下的稳定增益。**未排除**（未验证，不代表可行）：不同上下文长度 R、不同描述子/注入层/门控调度、更长训练、MAE 预训练后复用、其它数据或任务、其它物理量关系。
- 后续方向由项目记忆决定，本目录不再追加训练。
