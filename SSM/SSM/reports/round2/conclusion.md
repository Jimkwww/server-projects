# Round 2 结论（三个核心问题）

> 协议：15 个第一轮 checkpoint + 9 个新 run，全部用同一冻结评估协议（clean、order A/B、密集 CFO 网格 ±0.0001…±0.005、固定相位网格）。数据为窄带（无混叠），CFO 掉点为模型非不变性而非数据伪影。下文中「CFO 掉点」均指 order B（先扰动再归一化）下 clean→CFO 的 OA 下降。
>
> **修订记录（复核后）**：① 标准差统一为样本标准差（÷(n−1)），与第一轮口径一致；② A/B 差异区分「3 seed 均值 <0.8pp」与「逐 run 最大 1.28pp」；③ 低 SNR 并非全随机；④ 「clean 与鲁棒性双升是 SSM 特有」的结论**撤回**，待补 G_corr 对照；⑤ 能量与相关的互补机制**尚不确定**，不作载波补偿/状态控制解释。

## Q1：收益是否可靠？

**可靠。** S2_concat 的 CFO 鲁棒性优势在正确预处理（order B）下完整保留，3 seed 稳定：

- CFO=±0.005 掉点：S2_concat 0.072/0.055，vs S1 0.130/0.119、G 0.208/0.211。
- 归一化顺序：3 seed 平均的 A/B 差异在所有 CFO 下 <0.8pp（多数 <0.3pp）；逐 run 最大差异 1.28pp（S2_concat seed42 CFO=−0.005）。第一轮「先归一化再扰动」没有虚增优势。
- 15 个第一轮 checkpoint 在 order A 下 clean OA 逐 run 精确复现（无实现错误）。

## Q2：哪种描述起作用？

物理描述为 3 维 `[log-energy, Re(r), Im(r)]`（r=patch 内相邻样本复相关）。消融（均基于 S1 + token 融合，selector 不接收描述）：

| 配置 | clean OA（样本标准差） | CFO=+0.005 OA | CFO=−0.005 OA |
|---|---|---|---|
| S1（无描述） | 0.3813 ± 0.0076 | 0.2510 | 0.2625 |
| S1_energy（仅能量） | 0.3924 ± 0.0061 | 0.2438 | 0.2507 |
| **S1_corr（仅复相关）** | **0.3999 ± 0.0057** | **0.2974** | **0.3068** |
| S2_concat（完整描述） | 0.3879 ± 0.0063 | 0.3161 | 0.3325 |

- **仅复相关**：当前 clean 精度最好，同时改善较大频偏性能；相对 S1 的 clean 增益 **+0.48 / +3.01 / +2.08pp**（3 seed 全为正），±0.005 下也均为正——本轮最值得继续追踪的结果。
- **完整描述**：较大频偏下最好，但 clean 低于仅复相关。
- 因此存在一个实际取舍：**仅复相关更偏向 clean 精度，完整描述更偏向强频偏鲁棒性**，不能概括为「所有条件下都改善」。
- 能量与相关的关系：当前实验支持**两者联合改善较大频偏性能**，但作用机制**尚未确定**；暂不据此解释为载波补偿或电磁状态控制。

## Q3：是否依赖 SSM？——**撤回，对照未配齐**

之前的「clean 与鲁棒性双升是 SSM 特有」结论**撤回**。原因：此前的对照同时改变了**骨干**（SSM vs Transformer）**和描述组合**（仅复相关 vs 完整描述）——即比较的是「SSM+仅复相关」与「Transformer+完整描述」。而已知在 SSM 内部，完整描述的 clean 也低于仅复相关，故 G_full 的 clean 下降**不能**证明 Transformer 无法获得双重收益。

- 已知：G_full（Transformer+完整描述）clean 均值下降（0.3797 vs G 0.3869），频偏性能提升（CFO=±0.005 OA 0.2746/0.2680 vs G 0.1787/0.1763）。
- **待补**：`G_corr = G + 仅复相关`（3 seed），才能判断「表现差异是否与骨干有关」。
- 当前有效结论限于 **token 层描述融合**；尚不能证明「物理描述控制状态更新」有效（第一轮 S2 的选择器侧注入仍无明确优势）。

## 哪类 / 哪个 SNR 受益？

- **SNR**：主要收益集中在中高 SNR，但**低 SNR 并非全随机、也非无可改善空间**。例如 CFO=+0.005、SNR=−2 dB 时 S1 OA ≈ 14.7%，显著高于 24 类随机猜测的 4.17%。CFO=+0.005、SNR=18 dB 时 G=0.283、S1=0.400、S2_concat=0.536。
- **类**：受益最大的是**载波/窄带 AM 类与 ASK/PSK 类**（CFO=+0.005 时 S2_concat vs G 的 F1）：
  - AM-DSB-WC(19)：0.017→0.281；AM-DSB-SC(20)：0.034→0.464；AM-SSB-WC(17)：0.015→0.304；AM-SSB-SC(18)：0.008→0.256；
  - OOK(0)：0.041→0.583；4ASK(1)：0.016→0.356；BPSK(3)：0.007→0.487。
  - 高阶 PSK/QAM（5–7、10–16）在各模型下都难，CFO 下无差异；FM(21)/GMSK(22) 本身对 CFO 容忍。
  - 注意：AM 类需要「能量+相关」联合——仅相关（S1_corr）对 AM-DSB-WC 只有 0.016，全描述 S2_concat 达 0.281。这一互补的具体机制待定。

## 综合判断

1. 物理描述融合的 CFO 鲁棒性收益**真实、稳定、与归一化顺序无关**。
2. 两个候选并存：**S1_corr（clean 最优）** 与 **S2_concat（强频偏最优）**，取舍需由后续目标决定。
3. 「是否依赖 SSM」**尚无结论**：需补 `G_corr`（G+仅复相关）做同描述、不同骨干的对照；在此对照完成前，不宣称收益是通用还是 SSM 特有。
4. 长期「电磁专用骨干」目标可保留，但研究结论随证据推进；token 层融合有效 ≠ 物理描述控制状态更新有效。
5. 下一步：补 G_corr（3 seed）；再对 G/G_corr/S1/S1_corr 做统一 CFO 增强，判断融合收益在常规增强后是否仍存在。
