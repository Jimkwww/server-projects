# Round-4 结构实验：最终结论（负结果）

**一句话结论：本轮验证的四个结构假设（双向上下文、复数前端、双向+复数叠加、复数贯穿）全部为负结果——无一在 clean val 或 CFO 鲁棒性上超过单向 S1 或 G/G_corr 基线。** 结论对单向 S1 与 G_corr 的既有定位不构成改变，建议归档这些结构方向。

以下按任务书 8 个判定问题逐一回答，并严格区分「观察」「解释」「未证实机制」。

## 8 个判定问题

### Q1 双向扫描是否优于单向 SSM？
**否（净无收益，且不方向一致）。**
- A64 − S1 = −0.50 ± 0.36pp（clean），三种子一致略低。
- A128 − S1 = +0.45 ± 1.00pp（clean），三种子方向不一致（17 号 −0.70pp、42 号 +0.96pp、2026 号 +1.09pp）——正负号不统一是更直接的证据；样本标准差(1.00pp)大于均值仅作为次要旁证（不单独据此判定为噪声）。
- 唯一的稳定变化是低/高 SNR 的**互换**：双向把低 SNR OA 抬 ~+2pp（A64 0.1826 / A128 0.1841 vs S1 0.1621），同时把高 SNR 拉低（A64 0.6009 vs S1 0.6246），净效应≈0。这是观察，不是机制解释。

### Q2 A128 的收益能否与容量分离？
**不能。** A128 − A64 = +0.95 ± 1.28pp（clean），三种子方向不一致且量级小于种子波动，不可分离；A128 比 A64 多 ~28% 参数。A128 相对 S1 的微小正差同样缺乏方向一致性（见 Q1），不足以主张真实增益。

### Q3 复数前端是提升识别，还是只是精度/鲁棒性置换？
**不是提升，是明确的精度损失，且不换取鲁棒性（结论仅限当前配置）。**
- B_front − S1 = −4.05 ± 1.42pp（clean），三种子一致为负（−2.7/−5.6/−3.9pp）。
- 复数权重约束（ComplexLinear(8,88) 1408 参数、无偏置）比实数 `Linear(16,176)`（2992 参数）少且受限，主要损失集中在高 SNR（0.5596 vs 0.6246）。
- CFO 相对下降几乎不变（±0.005 处 B_front +13.89/+14.41pp vs S1 +14.31/+12.88pp）：复数前端**既不帮助也不损害** CFO 鲁棒性，只是降低了 clean 基线。
- **重要限定**：本轮 B_front 的损失可能被两个混杂因素放大，不能直接归因于「复数绑定」本身：(a) B_front 无偏置而 S1 有偏置（2992+176 参数）；(b) 复数前端初始化的等效实数矩阵各元素方差为 1/16（实/虚部各 N(0,1/2)、总复方差 1/8），是 `Linear(16,176)` 默认方差 1/48 的 3 倍，属初始尺度失配而非约束差异。Round-5 将以「匹配初始化 + 逐配置偏置对照」分离这两个混杂。

### Q4 双向 + 复数能否叠加？
**否。** C_bi_front − A128 = −5.57 ± 1.52pp（clean），三种子一致为负；C_bi_front 是全部 8 个模型里最差的（0.3778）。复数前端的损失不因双向而修复，双向也不因复数前端而增益。

### Q5 复数贯穿是否优于仅前端？代价如何？
**否（略差），但有参数效率的弱观察。**
- D_complex − B_front = −0.87 ± 0.41pp（clean），三种子一致略低。
- D_complex 只有 119 万参数（B_front 的 54%），clean 精度只低 ~0.9pp，是「参数少一半、精度几乎持平」的弱观察——但在绝对精度和速度上都不是胜利。
- eager PyTorch 下复数算术没有带来速度收益：D_complex 批 1 延迟 3.38ms、批 64 吞吐 8610 sps，与 B_front（2.95ms / 8744 sps）相当或更差。

### Q6 哪些结果三种子方向一致？
方向一致（可复现）的是：
- A64 ≤ S1（三种子一致小幅负）
- B_front < S1（一致大幅负，−2.7~−5.6pp）
- C_bi_front < A128（一致大幅负）
- D_complex < B_front（一致小幅负）

方向不一致（视为种子噪声）的是：A128 vs S1、A128 vs A64。

### Q7 新模型是否达到/超过 G 和 G_corr？
**否。** 最强新模型 A128 clean 0.4334，仍低于 G（0.4418）约 −0.8pp、低于 G_corr（0.4609）约 −2.8pp；在所有 CFO 点上同样全部落后。差距主要在高 SNR（新 SSM 模型高 SNR 普遍 0.54~0.62，G_corr 0.69）。

### Q8 是否有明确的精度/效率/鲁棒性胜利？
**没有。**
- 精度：无新模型超过 S1 的 clean 或 CFO。
- 效率：双向使 SSM 代价近翻倍（批 1 延迟 2.9ms→5.2ms，吞吐 9031→5000 sps，显存 1429→2432 MiB）而无精度回报；复数路径无速度收益。
- 鲁棒性：所有模型对全局相位几乎不变（相对 clean 的波动 <1pp，与此前「对全局相位旋转鲁棒」一致）；CFO 鲁棒性上无一新模型接近 G_corr。

## 观察 / 解释 / 未证实机制

**观察（数据事实）：**
1. 双向唯一的稳定效应是低↔高 SNR 互换（低 +2pp、高 −2~−2.4pp），净≈0。
2. 复数前端/复数贯穿降低 clean 精度（−4.05 / −0.87pp），且不改变 CFO 相对下降。
3. G_corr 在 clean 与所有 CFO 点继续领先（0.4609；±0.005 处仍 0.420/0.426），其复相关特征带来的 OOD 鲁棒性在 round3 已确立，本轮未受影响。
4. D_complex 以 ~54% 参数达到与 B_front 相当（略低）的精度。

**解释（有依据但非唯一）：**
- 复数前端权重共享（无偏置、real/imag 绑定）把 16 维实数 patch 映射压缩成 8 维复数 → 88 维复数的低秩映射，表达能力低于 `Linear(16,176)`；对依赖精细 I/Q 幅度/相位的高 SNR 调制方式尤为不利。**此解释仅针对本轮的 B_front 配置（无偏置 + 特定初始化）；偏置缺失与初始尺度失配（见 Q3 限定）是尚未排除的替代解释，Round-5 将分离。**
- 双向的「低 SNR 增益」可用「两个方向的时间积分增加了低信噪比下的证据聚合」解释，但这是事后解释，非预先登记。

**未证实机制（明确不声称）：**
- 不声称任何新结构获得「独特频偏补偿能力」或「物理状态恢复」。
- 不声称 D_complex 具有严格等变性（选择器读 Re/Im，头是实数）。
- 不把 3 种子当 3 个独立测试样本；样本标准差仅为种子波动量度。

## 最终建议

1. **归档** 双向（A64/A128）、复数前端（B_front）、双向+复数（C_bi_front）、复数贯穿（D_complex）四个方向：均无精度/效率/鲁棒性收益。
2. **保留** 单向 S1 为 SSM 对照；G_corr 继续作为实用强基线（clean 与 CFO 均最优）。
3. 与既有决策一致：**暂停新增状态模块**，不在 val 上继续扩展结构。

## 效率附注

- SSM 使用 eager PyTorch O(N log N) 并行扫描，非 fused SSM 内核；吞吐/延迟不代表生产 fused 实现。
- 长度扩展（L=1024→8192，8×）下 SSM 批 1 延迟仅 ~1.2×（S1 2.9→3.5ms），G 注意力 ~2.4×（1.07→2.59ms）；这是 SSM 的 O(N log N) vs 注意力 O(N²) 的结构性优势，但本轮 1024 长度下 G 绝对延迟仍更低。
