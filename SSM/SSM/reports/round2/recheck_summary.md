# 复核汇总（Part 1 决策门）

## 1. 复现校验（无实现错误）

- 15 个第一轮 checkpoint（G/S0/S1/S2/S2_concat × seed 17/42/2026）在 order A（第一轮协议：先 max_abs 归一化、再扰动）下 clean OA 与第一轮 `best_val.overall.oa` **逐 run 精确相等**（15/15，无 mismatch）。
- clean 下 A/B 两条流程完全一致（无扰动时两者等价），符合预期。

## 2. 归一化顺序 A vs B（核心）

| 变体 | CFO=±0.005 时掉点（clean→CFO，3 seed 平均） | A/B 差异 |
|---|---|---|
| G | A: 0.205/0.211，B: 0.208/0.211 | ≈0，鲁棒性差 |
| S0 | A: 0.150/0.161，B: 0.152/0.160 | ≈0 |
| S1 | A: 0.135/0.120，B: 0.130/0.119 | <0.5pp |
| S2 | A: 0.144/0.131，B: 0.141/0.129 | <0.3pp |
| **S2_concat** | **A: 0.069/0.063，B: 0.072/0.055** | **<0.8pp，且 B 在 −0.005 更优** |

**结论**：S2_concat 的 CFO 鲁棒性优势在 order B（先扰动、再归一化）下**完整保留**，甚至 −0.005 处略优。第一轮的「先归一化再扰动」没有虚增优势。鲁棒性排序在两种顺序下不变：**S2_concat >> S1 ≈ S2 ≈ S0 >> G**。

- A/B 差异：**3 seed 平均**差异在所有变体、所有 CFO 下均 < 0.8pp（多数 < 0.3pp）；但**逐 run**（单 seed、单 CFO）最大差异可达 **1.28pp**（S2_concat seed42 CFO=−0.005，A=0.3256 vs B=0.3385），均值 0.31pp（n=288）。归一化顺序不是主效应，但逐 run 噪声应区分于种子均值。
- 相位网格：π/2、π、3π/2 的旋转下 A/B **完全一致**（max_abs 对 ±90°/180° 旋转不变）；π/4 处有 <0.8pp 微小差异。相位鲁棒性同样不是归一化顺序伪影。
