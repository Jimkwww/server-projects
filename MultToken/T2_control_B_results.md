# 控制 B 结果：单尺度大核卷积前端 vs T0 / T2

日期：2026-09-23
目的：判断 T2（三尺度可学习卷积，短/中/长时间支持）的收益是否需要三种时间支持同时存在，
还是可以由「单尺度大核 + 同一 16 维瓶颈」复现。

## 0. 控制 B 是什么

```
前端：Conv1d(2, 16, kernel_size=32, stride=8, padding=12, bias=False)   # 无激活/归一/池化/残差
      -> Linear(16, 176, bias=True)
输入/掩码/网格/位置编码/主干/分类头/训练协议：与 T2 完全相同
L=1024 -> [B, 128, 176]  （T=128 不变）
前端参数 4016（conv 1024 + proj 2992），全模型 2,252,616
```

与 T2 的结构关系（已由等价性检查确认，见 §6）：
- T2 = 三条中心对齐卷积分支（k=8/16/32，通道 6/5/5）concat 到 16 维 + Linear(16→176)。
- 控制 B = 单个 k=32 卷积直出 16 维 + 同一 Linear。
- **B 的参数空间严格包含 T2 的前向映射**：把 T2 的三条分支权重按通道段拷进 B 的 k=32 核（短分支放中心 [12:20]，中分支 [8:24]，长分支整段 [0:32]，其余置零）并逐位拷贝 proj 后，前向与 logits 逐位一致（max_abs = 0.0）。
- 但**参数化/初始化/训练不等价**：T2 的有效参数集是「秩≤16 + 时间支持受限」的双线性簇（非线性流形，非线性子空间），B 是更宽的自由参数化。所以 B 不是 T2 的「等价重参数化」，而是 T2 的**超集放宽**——它多了自由短/中尺度混合，少了 T2 显式固定的三尺度结构。

## 3. 结论（按证据强度）

**结论：T2 一致优于 B（三种子、OA 与 F1 双指标全部为负），不能区分的情况不存在。**

- 相对 T2：三种子 OA 全部落后（−0.83 ~ −4.04 点），均值 **−2.54 点**；F1 同样全部落后，均值 **−2.35 点**。方向完全一致，无任一 seed 反超 → 证据强度：**强**。
- 相对 T0：OA 三种子里两负一小正，均值 **−1.82 点**（−1.82±2.01，含 1 个 +0.48 的例外）；F1 基本持平（−0.15 点）。→ B 不仅没有复现 T2，还**弱于最简单的恒等切块前端 T0**（在 OA 上）。

因此：**T2 的收益需要短/中/长三种时间支持同时存在，无法用单尺度大核（即便核长=32、同一 16 维瓶颈）复现。** 单尺度大核甚至比恒等切块更差。

## 4. 收益去哪了：逐 SNR 与逐类

### 4.1 逐 SNR（源码确认的事实）

B 的低 SNR（≤0 dB）并不差：0.1419（种子均值）与 T2 的 0.1460、T0 的 0.1356 同量级。**B 的全部劣势集中在高 SNR（>0 dB）**：0.5350 vs T2 0.5761（−4.1 点）、vs T0 0.5711（−3.6 点）。

这与 T3/T4 频域前端的「低 SNR 相对好、高 SNR 差很多」模式相同。调制识别在高 SNR 依赖精细瞬时时域结构（符号跳变、成形脉冲边缘），32 抽头卷积把这些瞬时信息摊平到跨 32 样本的滤波上。

## 5. 过拟合信号（源码确认的事实，解释）

B 的训练曲线明显过拟合：
- val loss 高达 3.6~4.2（T0/T2 约 1.9~3.1）；
- train_oa 在第 50 epoch 达到 ~0.96，而 val_oa 在 epoch 37~41 就见顶（0.35~0.39）后停滞/回落。

对照：T0 的恒等切块把 8 样本原始 I/Q 直接交给投影，信息无损失；T2 至少保留了一条 k=8 的「近恒等」短尺度路径。B 的 16 个通道全是 32 抽头滤波器，缺少短尺度/恒等路径，更容易对训练集拟合出非泛化的滤波。

## 6. 等价性检查回执（源码确认的事实）

- 前端参数：conv 2×16×32=1024 + proj 16×176+176=2992 = **4016** ✓（比 T2 的 3568 多 448）。
- 全模型参数：**2,252,616** ✓（= T0 2,251,592 + 1024）。
- 权重转移等价：把 T2 三分支权重按通道段拷入 B（短分支 → 核 [12:20] 中心对齐，中分支 → [8:24]，长分支 → [0:32]，其余置零；proj 逐位拷贝）后，eval 模式 tokenizer 前向与全模型 logits **逐位一致（max_abs = 0.0）**。
- 正式训练 3 种子**未使用**转换权重、未从 T2 checkpoint 续训，均随机初始化，协议与 T0/T2 相同（cls_dev 划分、max_abs 归一、dim=176/depth=6/heads=4、batch=128、lr=3e-4、50ep、fp32、同优化器/调度/增广/checkpoint 规则）。

## 7. 成本

- 参数：全模型 2,252,616（B）vs 2,252,168（T2）vs 2,251,592（T0）。B 相对 T2 仅 +448（+0.02%），成本差异可忽略。
- 吞吐：单 epoch 训练 ~7.6 s（~2620 samples/s，peak_train_allocated ~1.48 GB），三种子 50 ep 各约 6.3 分钟，与 T0/T2 同量级（资源：A100-40G 单卡；本轮在 GPU 1，与历史 T0/T2 不同卡，吞吐绝对值仅作参考，不作跨方法硬比较）。
