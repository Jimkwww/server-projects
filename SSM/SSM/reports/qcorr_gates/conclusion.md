# Q_corr 物理门控轮结论

在 Q_corr（S1 复对角 MIMO SSM + 8 通道复递归滤波复相关辅助分支）基础上，把由 IQ 算出的两个标量描述子接入 S1 的写入门与历史衰减门：`c_n=|r_n|`（块内滞后 1 归一化复相关强度）调制写入门 `g=σ(z^g+w·c̃_n)`，`d_n=|r_n−r_{n−1}|`（相关变化，首块置 0）调制衰减参数 `δ=softplus(z^δ+v·d̃_n)`；`w`/`v` 逐层逐状态零初始化（128/layer × 6 层 = 768/门）。`_token_*` 是把同样标量经零初始化无偏置 Linear 一次性加入输入 token 的同信息对照（仅间接到达门）。10 模型（6 新 + 4 历史基线）统一 11 条件 order-B 重评估，差异以百分点 (pp) 计。

本轮 6 个变体里 clean 最优的是 **`Q_corr_token_cd`**（0.4606，+0.62 pp over Q_corr），且 seed 间方差最小（0.0043）。但该增益相对 seed 噪声并不显著（+0.62±0.70 pp），也仍未超过 Global 侧最优 `G_Q_corr_frozen`（0.4701）。三个 `_gate_*` 直接门控变体 clean 全部略低于 Q_corr（−0.10 ~ −0.16 pp）。**结论：加写入门/衰减门的标量调制在干净数据上无实质增益，最佳也只是与 G_corr 打平（token_cd 0.4606 vs G_corr 0.4609）。**

## 2. ±0.005 鲁棒性最优与逐类权衡

| 模型 | clean | +0.005 | −0.005 | ±0.005 相对下降 |
|---|---|---|---|---|
| Q_corr | 0.4544 | 0.3459 | 0.3462 | −10.84 / −10.82 pp |
| Q_corr_gate_c | 0.4528 | 0.3482 | 0.3397 | −10.46 / −11.30 pp |
| Q_corr_gate_d | 0.4534 | 0.3484 | 0.3372 | −10.50 / −11.62 pp |
| Q_corr_gate_cd | 0.4533 | 0.3497 | 0.3421 | −10.36 / −11.12 pp |
| Q_corr_token_c | 0.4557 | 0.3447 | 0.3433 | −11.10 / −11.24 pp |
| Q_corr_token_d | 0.4572 | 0.3409 | 0.3344 | −11.62 / −12.28 pp |
| Q_corr_token_cd | 0.4606 | 0.3462 | 0.3306 | −11.44 / −13.00 pp |
| G | 0.4418 | 0.4058 | 0.4043 | −3.60 / −3.75 pp |
| G_corr | 0.4609 | 0.4200 | 0.4255 | −4.09 / −3.54 pp |
| **G_Q_corr_frozen** | 0.4701 | **0.4597** | **0.4559** | **−1.04 / −1.42 pp** |

±0.005 下最优仍是 **`G_Q_corr_frozen`**（绝对 OA 0.4597/0.4559，相对下降仅 ~1 pp）。S1 侧的 6 个新变体与 Q_corr 一样在 ±0.005 下坍塌到 ~0.33–0.35（下降 ~10–13 pp），门控/ token 标量都没有缓解 S1 的 CFO 脆弱性——这与上一轮结论一致：**该复相关特征的 CFO 鲁棒性来自它与主路径（全局注意力）的交互，而非特征本身；接到 S1 上无论怎么调制门都无济于事。**

逐类权衡（`Q_corr_gate_cd` − `Q_corr` 的 Macro-F1，clean，3 seed 均值 pp）：
- **显著受益**：32PSK +6.16、FM +4.58、AM-SSB-SC +3.36、16APSK +3.02、AM-DSB-WC +2.11、128QAM +1.92、32QAM +1.85。
- **显著受损**：16PSK −4.89、BPSK −3.43、32APSK −2.17、64QAM −1.98、8PSK −1.61。

即写入门+衰减门让高阶相移/APSK/FM 类涨、却让 BPSK/16PSK/32APSK 跌，是一张真实的类别间权衡表，而非均匀提升。

## 3. 门（gate）vs token：间接 token 优于直接门控

| 对照 | clean 差值（pp） |
|---|---|
| gate_c − token_c | −0.29±0.35 |
| gate_d − token_d | −0.37±0.60 |
| gate_cd − token_cd | **−0.73±0.78** |

三个配对在 clean 上 token 全部优于 gate（gate_cd 比 token_cd 低 0.73 pp）。机制诊断（零化消融，即把 `w/v` 或 `token_proj` 置 0 还原成 Q_corr）进一步证实：`token_cd` 学到的标量贡献 = **+1.54 pp**，而 `gate_cd` 的标量贡献只有 **+0.32 pp**——同样一份 (c,d) 信息，经 token 路径被利用得比直接门控有效约 5 倍。

原因可从门控细节看出：学到的 `|w|`/`|v|` 每层约 0.5–0.75（非零），但实际对门的扰动极小——写入门 g 的 RMS 位移仅 ~0.013、衰减因子 ρ 的 RMS 位移仅 ~0.006（clean），说明 `c/d` 经过标准化后对 selector 已经算出的门 logit 几乎没有额外信息；直接乘在门 logit 上只有 O(0.01) 的 sigmoid 输出变化。token 路径则让 selector/主干更灵活地利用这维信息，故略好。

## 5. 一句话总结

**在 S1 的写入门与衰减门里直接注入 IQ 标量描述子（c=|r|、d=|r_n−r_{n−1}|）几乎没有价值：门控变体 clean 反而略降（−0.1 pp），同信息的 token 对照略升但最佳 `Q_corr_token_cd` 也只 +0.62 pp、且 ±0.005 下降最多（−13 pp）；直接门控 vs 间接 token 的对比说明这维信息经 token 路径被利用得约 5 倍于直接门控（+1.54 pp vs +0.32 pp），但两者都无法缓解 S1 的 CFO 脆弱性——该特征的鲁棒性来自与全局注意力主路径的交互，靠门控调制无法复制。全局侧 `G_Q_corr_frozen`（clean 0.4701、±0.005 掉 ~1 pp）仍是全线最优。**
