# 实验方案二：对齐关系参与电磁信号注意力

版本：v1.0；日期：2026-09-21。状态：研究假设与可执行实验设计，尚无实测结果。

## 1. 交给服务器 agent 的任务摘要

在当前可复现的 Global Transformer 上，固定原始 I/Q 切块、token数量、主干和分类头，研究局部片段间的时延/相位相关关系是否能改善注意力计算。

第一阶段采用“标准内容注意力 + 物理关系偏置”，不直接替换全部 QK，也不对 V 做相位旋转或时延变换。先验证关系是否有用，再考虑更深的对齐聚合。

本实验独立于 `01_multiscale_tokenization_experiment.md`。不引入小波包、STFT、多尺度 tokenizer，不同时更改 Swin 窗口/层级，不在本阶段做二者融合。

不要将初步相关性、一次准确率提升或注意力热图解释为已验证的“物理等变大模型”。

## 2. 研究问题及边界

候选问题：普通 token 点积能学习任意特征匹配，但未显式要求比较对小幅时延、相位变化具有可解释行为。显式局部相关关系是否在有限数据/计算下提供更合适的归纳偏置？

H1：局部复相关为 attention 提供标准 QK 没有容易学到的有用补充。

H2：有限时延候选优于只计算零时延关系，尤其在时间错位条件下。

H3：保留相关相位与时延分布，比仅取最大相关幅度更有利于保留判别信息。

H4：收益可能只是增加了一条原始信号旁路、更多参数、局部上下文或搜索极值偏差；必须通过控制实验区分。

同类调制的两个独立随机符号片段不一定波形相关。周期相关强也不一定意味着同类。该机制可能仅适用于部分信号、部分条件；负结果允许推翻假设。

## 3. 基线核验和数据协议

先从服务器记录生成 `baseline_audit.md`：数据版本/划分哈希、N、P、步长、T、D、层数/头数、位置编码、归一化、优化器/调度、batch、增强、步数、种子、checkpoint规则及当前基线复现。

当前文档不提供确定历史准确率、不假设最新审计结论，也不指定不存在的服务器路径。保持数据源、训练/验证/测试隔离；同一底层波形的不同相位/时延/噪声变体不得跨划分。

频偏、相位、时移的标签保持性依任务判定。调制分类的某些扰动可能不改类别；频偏估计、到达时刻估计等任务的标签必须随变换更新。

## 4. 最小可实施结构

标准路径：原始 I/Q → 原切块嵌入 → Global Transformer → 原分类头。

新增关系路径：当前模型实际可见的 I/Q → 局部关系片段 → 多候选时延相关 → 小型关系映射 → 加到注意力 logits。

普通注意力内容项和原位置项继续保留：

\[
L_{ij}^{(l,h)}=q_i^{(l,h)\top}k_j^{(l,h)}/\sqrt{d_h}
+B_{ij}^{(l,h)}+g_{l,h}\,r_{ij}^{(h)}.
\]

然后按原attention mask沿 j 做 softmax，按原方式聚合 V。g 是可学习门控，建议初始化为0；关系映射不能同时全零初始化，以免门控与映射互相造成零梯度。g=0时在同dtype/计算路径下应与基线数值一致。

关系在每次输入前向时计算一次，在层间共享原始描述；不同头可有不同小映射。先只注入第一层，后消融前半层/所有层，避免成本与干扰无控制增长。

本方案不降低标准全局注意力 O(T²) 复杂度；额外相关计算通常增加成本。未经实测不能声称加速。

## 5. 局部片段定义

设第i个原token对应中心 c_i。最小实现取其原始 P 点复片段 z_i，保持顺序。候选时延半径 d 建议为 `min(2, floor(P/4))`，先只用整数采样时延。

若 P 太短（例如4）导致相关估计不稳定，可设固定关系长度 R=2P或4P，在 c_i 周围取对齐的上下文片段；token本身仍然不变。必须加入同R上下文的零时延/普通关系控制，并明确这个版本额外访问了跨patch信息。

默认不循环移位片段；使用真实有效重叠。边界padding不参与统计。记录每对片段、每个时延的有效样本数。上下文片段彼此有重叠时，加入“屏蔽近邻关系偏置”的消融，防止共享采样导致平凡相关占主导；只屏蔽新增偏置，不删除原标准注意力边。

频偏搜索、分数时延、DTW均不是首轮内容。

## 6. 复相关描述的精确定义

对 τ 属于 {-d,...,d}，定义有效重叠索引集合 Ω_ijτ：所有 z_i[n] 和 z_j[n+τ] 均来自当前可见、非padding样本。计算：

\[
C_{ij}(\tau)=\sum_{n\in\Omega_{ij\tau}}z_i[n]z_j^*[n+\tau],
\]

\[
E_i(\tau)=\sum_{n\in\Omega_{ij\tau}}|z_i[n]|^2,
\quad E_j(\tau)=\sum_{n\in\Omega_{ij\tau}}|z_j[n+\tau]|^2,
\]

\[
\rho_{ij}(\tau)=C_{ij}(\tau)/(\sqrt{E_i(\tau)E_j(\tau)}+\epsilon).
\]

默认不对每个片段减均值，因为这可能删除有意义分量；若加入去均值必须独立消融。所有 τ 使用各自相同重叠区的分子和分母，不能用全片段能量归一化不同重叠长度。

数值要求：

- 归一化输入下epsilon先取1e-6，配置化并做极低能量敏感性检查；累计与除法用float32，即使主干BF16。
- 建议最小有效样本数 `max(4, ceil(R/2))`。不满足则标为无效，不能靠极少样本得到高相关。
- 低能量/无有效候选时令新增关系偏置为0，返回有效性标识，不产生NaN。
- 首版自相关对角新增偏置设0；否则零时延对角高相关可能使其只学到自注意。
- 归一化会降低绝对幅度影响，另外保留 log能量或能量比作为可选关系特征，并单独消融；原始内容路径不因此删除。

### 6.1 首选表示：完整小规模时延描述

每对token的描述：

`f_ij = concat_tau(Re(rho), Im(rho), abs(rho), overlap_fraction, valid_flag)`。

d固定时维度很小。送入各头共享或分头的小MLP：隐层宽建议16，输出H维偏置。先用线性映射控制；关系偏置可用tanh限制范围，门控控制强度。记录映射参数量。

避免首版依赖angle/argmax：低相关时相位不稳定；多周期峰的期望时延可能落在没有真实峰的位置。保留整个小向量比强行压成一个“最优时延”更稳妥。

### 6.2 可选可解释摘要

以a_τ=abs(rho_τ)²，p_τ=softmax(a_τ/temperature)，得到软加权相关强度、候选分布熵、加权实部/虚部。温度初始0.1，验证集小范围选择，不在测试集调参。

期望时延只用于辅助显示；多峰时同时展示完整分布。另保留hard-max幅度版本作控制，以检测多候选极值选择的假阳性。

### 6.3 关于物理性质，允许和不允许的结论

若z_i和z_j共同乘e^{jφ}，rho保持不变，这是该描述量的代数性质。若分别乘不同相位，相关幅度不变，但相关相位改变。它们不自动保证整个网络相位不变或等变，因为原始嵌入、QK/V、非线性和读出可能不满足条件。

在简单共同频偏变换下，相关相位会随时间间隔和τ发生可解释变化；因此不能声称复相关消除了频偏。时移还可能改变patch边界，单纯时延搜索也不自动保证整网时间平移不变。

不对任意隐藏维度做“物理时移”，也不把普通实值embedding的维度对直接叫I/Q。学习复表示需要结构约束，是后续版本。

## 7. 核心实验矩阵

| ID | 内容 | 要排除/检验的解释 |
| --- | --- | --- |
| A0 | 原始Global | 主基线 |
| A1 | 标准QK + 零时延复相关偏置 | 仅相关旁路是否有效 |
| A2 | 标准QK + 多时延相关幅度描述 | 时延搜索和相位不敏感的作用 |
| A3 | 标准QK + 多时延完整复描述 | 相对相位是否提供增益；主候选 |
| A4 | 标准QK + 同R上下文的普通实值点积/MLP关系 | 额外上下文和参数是否已足够 |
| A5 | 标准QK + 与A3同分布但打乱对应关系的偏置 | 正确配对关系是否重要 |
| A6 | A3只用关系项、移除QK | 诊断相关性是否足以替代内容；非主候选 |

A5在同一样本内重新配对关系矩阵的j索引，保持原QK、位置和V不变；固定随机策略并多种子，避免跨样本引入另一种正则化解释。该控制改变语义匹配但不降低新增计算预算。

至少对A0、A1、A3使用相同的相位/时移增强协议。另对A0与优选候选执行增强开/关的2×2控制：若优势被简单增强消除，应如实报告。

阶段性消融：R=P与2P/4P；τ=0与小范围搜索；实虚部/幅度；近邻偏置屏蔽；映射线性/MLP；第一层/前半层；能量附加项开关。只对入围候选做，不执行全组合。

## 8. 执行步骤

### 阶段0：代数与实现正确性

1. 复用并复现A0。记录g=0的输出一致性，检查g及映射梯度可学习。
2. 与朴素双循环参考比较rho；验证共轭方向、时延符号、有效重叠和归一化。
3. 用同片段加已知整数时延/相位差的合成样本验证峰位置；相位符号由公式及合成真值校准，不凭图猜测。
4. 对全零、低能量、边界短重叠、BF16主干检查有限值。
5. 验证共同相位旋转下描述不变；同时明确整网不一定不变。

### 阶段1：先做关系诊断，不训练大模型

构建四类配对：同波形受控变换、同类别独立符号、不同类别、独立噪声。每类用固定种子生成足够样本，例如1000对，平衡SNR/长度。

比较最大/软相关强度分布、真假匹配区分度、时延误差，以及随R、d、SNR变化的行为。R很短或d过大时随机噪声也可能出现高峰。

同类别独立符号若无相关，不应直接停止全部实验，但应收缩机制解释：它可能只帮助重复片段/局部一致性而非类别匹配。若同波形受控变换都识别不出或噪声误匹配严重，先修实现或调整R，不进入大规模训练。

### 阶段2：固定预算监督筛选

先运行A0/A1/A2/A3/A4，同筛选种子、训练子集和步数。建议种子17；若已有规范则复用。只用验证集筛选。

若A3有潜力，再运行A5和有限消融；A6仅用于诊断。优先R=P，若统计太不稳定再引入扩展上下文控制。

### 阶段3：多种子确认与扰动泛化

A0和最多两个入围候选完整训练，建议17/42/2026三个配对种子；报告均值/标准差/逐种子差值。测试集在方法和超参选择完成后统一评估，不反复筛选。

### 阶段4：预训练兼容性

监督和机制证据成立后再接MAE。相关路径只能看到编码器允许看到的信号，不能从完整未遮挡I/Q计算rho后送给编码器。

若关系长度R跨patch，对每个相关样本对都应用原始可见mask；有效样本不足时关闭关系项。隐藏目标不能经邻接halo、相关矩阵、门控或全信号归一化统计泄漏。原始归一化如何处理与基线保持一致并注明。

若编码器删除mask token，保留可见token的原始坐标，按坐标构建关系，不能把压缩后索引当原时延。解码器可采用既有位置方案，不额外引入未计量的物理关系分支。

## 9. 扰动与任务评估

同分布：OA、macro-F1、逐类/逐SNR结果和混淆矩阵。

受控泛化：

- 初相位：x'=x exp(jφ)，测试多角度；另设训练未覆盖的角度区间，记录训练增强。
- 时延：优先长记录重裁剪，或使用带有效性mask的平移；循环移位只作独立诊断，不伪装成真实信道。
- 频偏：x'=x exp(j2πδn)，δ单位为cycles/sample；有采样率时才换算Hz。测试范围保证不产生非预期混叠，先使用数据合理范围。
- SNR：原噪声水平已知时按功率计算增量噪声；已有低SNR不能用加噪提升至高SNR。
- 组合扰动：只在单因素结果清楚后使用，防止原因不可辨别。

对参数估计任务同步更新标签，不能统一要求输出不变。重点检查对齐是否误删频偏/到达时刻/相位相关判别信息。

报告稳定性可以使用同一波形变体的预测一致率及特征距离，但不能将“一致但全错”判为鲁棒；必须同时报告准确率/误差。

## 10. 计算实现与效率

直接算法的关系成本约O(B T² R K)，K=2d+1；实际可通过按τ构造加权矩阵乘法、分块计算或共享描述降低开销。不要一次物化[B,T,T,R,K]张量。

第一版保留全局关系，为机制验证服务。T很大时先减batch或分块，不能悄悄改变注意力连接。若确需候选边采样，单列为后续稀疏版本，并加入同预算随机/局部/全局控制。

GPU测量：同设备、精度、batch、输入长度、编译和attention实现；预热后至少100次、同步计时。记录前端关系计算、主干、端到端中位/p95延迟、吞吐和显存。

新增dense bias可能导致FlashAttention/SDPA后端回退。报告真实后端；若候选使用慢路径，对A0补充相同路径控制以区分算子回退与算法成本，同时保留A0最优路径作实际部署参照。

## 11. 判断标准与失败处理

支持继续：多个种子收益方向一致；受控错位条件有特定改善；正确关系优于打乱关系；相位/时延分布行为与合成真值一致；实际成本可接受。

不足以支撑机制：A4已达到全部收益，说明额外上下文可能是主因；A5不下降，关系对应性可能不重要；A1≈A3，说明无需时延搜索；只有训练集改善；所有头只加强对角/邻接；长序列成本不可接受。

若幅度相关导致频偏/相位任务退化，优先保留完整复描述及原内容路径，而非扩大不变性。如果g长期近0，检查梯度后允许结论为该数据不需要新增机制，不人为强迫大门控。

任何工程提升门限必须在测试集评估前确定。多种子均值提升不等于已经证明理论不变性或架构普适优势。

## 13. 后续融合，仅保留接口

两条路线独立验证后，执行tokenizer×attention的2×2对照。设四组同一指标为S00、S10、S01、S11，交互项I=S11-S10-S01+S00；I需要结合种子波动解释，不能直接假设两个收益可加。

第一版融合可从“多尺度token + 对应原始时间支持的关系描述”入手，但必须处理尺度、支持长度、频带和padding；若不同token共享同一片段，关系可能平凡重复。直接跨子带相乘通常没有自动的物理对应，需独立设计，当前不实施。

## 14. 文献与创新边界

- [复值Transformer、相对位置和可分离卷积用于调制识别](https://ieeexplore.ieee.org/document/11037473/)：说明复值关系和相对位置本身已有先例；公开摘要不足以确认全部消融细节。
- [Autoformer](https://arxiv.org/abs/2106.13008)：自相关聚合已有先例，不能把相关计算本身作为首次贡献。
- [BigBird](https://arxiv.org/abs/2007.14062)：后续如做随机稀疏边，需要区别于通用稀疏注意力。

互相关、匹配滤波、相位不敏感比较均是成熟思想。本方案的潜在贡献需要由电磁表征学习中的具体失败机制、受控关系建模及泛化证据支撑；开展正式论文前还需针对complex/correlation/equivariant/alignment attention做系统查新。
