# 多尺度 token 化筛选分析（Phase 1）

版本 v1.0；日期 2026-09-21。对应 `01_multiscale_tokenization_experiment.md` 第 8 节阶段 1（低成本筛选）与第 10 节交付物。全部单种子（seed=17；T0 另加 seed=2024 交叉验证），全量 50ep，同一 Global 主干/分类头/训练协议，仅前端不同。

## 1. 结论摘要

1. **框架一致性验证通过**：T0 seed2024 的 val OA = **0.3868589699268341（epoch 21）**，与冻结基线 `SwinE/pretrain_v1/runs/sup_global_50_s2024` **逐位一致**（连最优 epoch 都相同）。tokenizer 框架与冻结基线训练协议完全等价，后续差异可单因素归因于前端。

2. **频域/小波前端（T3/T4/T5）在 RML2018A 上明显更差**：T3 WPT(Haar/db4) 比 T0 低约 **−6.8 / −6.7 点**，T4 DWT 低 **−11.5 点**，T5 STFT 低 **−11.1 点**。H3（小波包提供更合适的归纳偏置）**不支持**。

3. **T2 可学习多尺度卷积 ≈ T0**（+0.09 点，噪声级），但 macro-F1 明显更高（+1.6~3.6 点，见 §4），值得 Phase 2 用固定随机滤波器控制区分「学习性」与「多尺度感受野」。

4. **T1 块内 DCT（控制组）≈ T0 −0.9 点**：正交基变换（可逆、不引入新信息）确实无增益，符合预期，排除了「换基就涨点」的解释。

## 3. 假设检验（对应文档 §2）

- **H1（多尺度表示改善跨条件迁移）**：本阶段无跨采样率/符号率数据（h5 无元数据），**未检验**。
- **H2（复值多尺度保留相位）**：所有前端都保留复值（I/Q 配对），未做幅度/功率删除对照，**未单独检验**；T5 复数 STFT 明显退化不支撑「频域复值更优」。
- **H3（小波包归纳偏置更合适）**：**不支持**。T3/T4 在相同 T/D/参数预算下明显劣于 T0。
- **H4（收益只是预算/平滑/训练预算）**：T0/T1/T3/T4/T5 参数**完全相等**（2251592），T2 仅多 576（+0.026%），故 T3/T4/T5 的退化**不是参数预算**造成；退化的原因是表示本身更难学（或位置编码不匹配，见 §5）。

## 4. 关键发现：频域前端「低 SNR 略好、高 SNR 差很多」

T3/T4 相对 T0 在低 SNR 段（≤0 dB）并不差（T3 db4 低 SNR 0.1538 反而比 T0 0.1333 高 +2.0 点），但高 SNR 段大幅落后（T3 db4 0.4522 vs T0 0.5839，**−13.2 点**），总 OA 被高 SNR 损失主导。

- 解释方向：调制识别在高 SNR 下依赖精细的瞬时时域结构（符号跳变、成形脉冲边缘），小波/STFT 的跨样本滤波把这些高频瞬时信息摊平到多个系数上，且临界采样+periodization 边界引入混叠/周期延拓伪影。
- 这一「低 SNR 相对更好」的规律**不能**直接当成小波噪声鲁棒的证据：低 SNR 段的绝对准确率依然很低（~0.15），且是单种子；若要验证需专门的低 SNR 增广/合成诊断集（文档 §6.3 任务层诊断）。

## 5. 失败例子与潜在混淆（不把负结果当最终结论）

这些是小波/STFT 前端在**本实现协议下**明显退化的可能混淆因素，Phase 2 需逐一排除后才可下最终判断：

1. **位置编码不匹配**：T3/T4/T5 采用「频带优先（band-major）展平 + 正弦绝对位置」，展平索引 ≠ 实际时间，且跨频带 token 混排。文档明确要求「元数据开关消融」——用 `time_center + scale/band` 元数据代替正弦位置。T0 的索引天然等于时间，占优。
2. **边界方式**：统一用 `periodization`（周期延拓）保证临界采样，但对非周期 IQ 片段有边界伪影；`reflect/symmetric` 不临界采样但更物理，需另测（会改变实际 T，需记录）。
3. **共享投影**：T3/T4/T5 各频带共用同一个 `Linear(2P→D)`；若频带间尺度差异大，共享投影可能不足，但分频带投影会加参数，需与同预算 T0 对照。
4. **T2 的 F1 提升是否来自「可学习」**：T2 是唯一可学习前端；其 macro-F1 0.3929 相对 T0 seed17 0.3573 高 +3.6 点，但 T0 seed2024 的 F1 为 0.3766（seed 噪声），T2 相对 2024 只高 +1.6 点。需「固定随机滤波器」与「T0 多种子」区分。

## 6. 下一步（Phase 2 消融，按优先级）

1. **T0 与 T2 多种子**（3 种子）确认：T2 的 OA 持平、F1 是否稳健更优；T0 补 seed 17/42/2026 之外的种子以锚定筛选对照。
2. **T2 固定随机滤波器控制**：冻结卷积权重（随机初始化不动）→ 若 F1 优势消失，则收益来自「可学习」，否则来自「多尺度感受野」。
3. **T3 元数据位置编码开关**（只对 WPT，选 db4）：`time_center + band_id` 嵌入 vs 展平正弦位置；同时试 time-major 排序 vs band-major。
4. **T3 边界方式**：periodization vs reflect（记录实际 T 变化）。
5. 视 3/4 结果决定是否做「幅度/功率删除」对照（H2）与 hann+hop/2 重叠 STFT（T5 变体）。

**不建议**：对 T3/T4/T5 投入可学习小波/lifting（文档 §5 T6/T7）——固定表示尚未表现潜力，直接上可学习树属于无边界结构搜索。

## 8. Phase 2 消融结果（2026-09-21，GPU 1，全部 rc=0）

按 §6 顺序执行 7 个 run，结论如下。

### 8.1 T0 / T2 多种子（锚定对照 + F1 稳健性）

| 前端 | seed17 | seed42 | seed2026 | OA 均值±std | F1 均值 |
|---|---|---|---|---|---|
| T0 | 0.3933 | 0.3837 | 0.3837 | 0.3869±0.0055 | 0.3714 |
| T2 | 0.3942 | 0.3913 | 0.3968 | 0.3941±0.0028 | 0.3935 |

- T0 三种子均值 0.3869，落在基线 0.3835±0.0034 的 ~1σ 内，筛选对照锚定成立。
- **T2 的 macro-F1 优势稳健**：三种子 T2 F1 全在 0.393~0.394，而 T0 在 0.357~0.384 波动；T2 F1 均值 0.3935 vs T0 0.3714，**+2.2 点，跨 3 种子一致**，排除 §5.4 的 seed 噪声疑点。OA 上 T2 也稳定略高（+0.7 点），但幅度小于 F1（F1 对难分类/小类的提升更敏感）。

### 8.2 T2 固定随机滤波器控制（可学习 vs 多尺度感受野）

- `t2_frozen` seed17：**OA 0.3760 / F1 0.3532**，低于同种子 T2（0.3942/0.3929）和 T0（0.3933/0.3573）。
- 结论：T2 的收益**来自「可学习的多尺度滤波器」本身，不是「多尺度感受野」这一归纳偏置**——随机固定多尺度滤波器不仅没增益，F1 还略低于 T0（0.3532 vs 0.3573）。§5.4 的疑问得到回答：是「可学习」，不是「多尺度」。

### 8.3 T3(db4) 元数据位置编码开关

- `t3_meta` seed17：**OA 0.3391 / F1 0.3071**，相对正弦位置 T3（0.3260/0.2926）**+1.3 点 OA、+1.5 点 F1**，但相对 T0（0.3933）仍差 −5.4 点。
- 结论：§5.1 的「展平正弦位置错位」只解释 T3 退化的一小部分（~1 点），**不是主因**。T3 的劣势主体来自小波包表示本身（跨样本摊平瞬时结构 + periodization 边界伪影 + 频带间共享投影）。位置编码方向不值得继续投入。

### 8.4 T4(DWT) 元数据位置编码

- `t4_meta` seed17：**OA 0.2679 / F1 0.2425**，相对正弦位置 T4（0.2782/0.2679）**反而 −1.0 点 OA**。
- 结论：元数据位置编码对 T4 无帮助甚至略负；DWT 的退化与位置编码无关，彻底坐实「小波类表示在本任务上不成立」（H3 不支持）。

## 9. Phase 2 总结论

1. **T2（可学习三尺度卷积前端）是唯一优于 T0 的方案**：OA +0.7 点、F1 +2.2 点，3 种子稳健；且收益明确来自「可学习」而非「多尺度感受野」。
2. **小波/STFT 前端（T3/T4/T5）最终判定为负结果**：元数据位置编码（本阶段最有力的挽救手段）仅带来 ≤1.3 点的局部改善，无法挽回高 SNR 段 −13 点量级的损失；DWT 甚至更差。H3 不支持，归档。
3. **T1（DCT）无收益、T2 冻结随机无收益**，说明「块内正交变换」与「固定多尺度滤波」都不如朴素可学习投影——学习能力是关键变量。

## 10. 后续建议（供决策，不自动执行）

- **若继续 MultToken 主线**：把 T2 作为新的输入前端，做小范围结构搜索（kernel 集合 {8,16,32,64}、分支数、是否加 1×1 残差 / 归一化），并在 SwinE 的微调/跨条件协议下复测 T2 是否同样稳健（本阶段只测了从头 50ep）。
- **若收敛本线**：MultToken 结论可写为「在固定 Global 基线上，可学习多尺度卷积 token 化带来稳健但有限的提升（OA +0.7 / F1 +2.2），频域与小波 token 化不成立」。T2 是否并入 SwinE 主线，由用户定夺。
