# Round 3 复核结论（G_corr 对照 + CFO 增强 + 扩展频偏）

> 协议：24 个 checkpoint（G / G_corr / S1 / S1_corr × 3 seed，无增强与 CFO 增强各一组），全部 50 epoch，best 按 clean val OA 最早 tie 选择。冻结评估统一 **order B**：原始 IQ → 注入 CFO → max_abs 归一化 → 重算物理描述 → 模型；均值用**样本标准差（ddof=1）**。CFO 网格为原密集网格 + 扩展点 ±0.003 / ±0.004 / ±0.0075 / ±0.01 / ±0.02。**全程只用 val，test 未参与。**
>
> 频偏合法性：沿用 round-2 带宽分析——全部 24 类 −30 dB 带宽 ≤ 0.18、无混叠 CFO 范围 ≥ ±0.43 cycles/sample，故扩展点 ±0.02 仍在无混叠范围内，掉点反映模型的频率平移非不变性，不是数据混叠伪影。**「增强范围外」仅指超出人工注入的 ±0.002，不代表真实数据总频偏范围**（数据集含 OSC 振荡偏移，FM 类本征约 +0.031）。

## 一、三个核对问题的直接回答

**Q1：增强后的 G_corr 是否三个种子都优于 G？**
- clean：**是**（逐种子 +2.08 / +1.57 / +2.08pp）。
- CFO=−0.005：**是**（+1.86 / +1.73 / +2.79pp）。
- CFO=+0.005：**不全是**（+2.21 / **−0.42** / +2.47pp，seed42 微负）。
- 结论：clean 与 −0.005 全种子一致；+0.005 处 G_corr 平均仍领先（+1.42pp）但非逐种子严格成立。

**Q2：S1_corr 在 ±0.005 相对 S1 的 ~9.5pp 收益是否三个种子都成立？**
- **是。** +0.005：+7.69 / +10.19 / +10.64pp；−0.005：+9.74 / +11.09 / +7.50pp。三个种子同号、幅度相近。

**Q3：G_corr 相对 S1_corr 的优势是否跨种子一致？**
- **是。** clean 逐种子 G_corr−S1_corr = +2.85 / +1.63 / +2.40pp；CFO=+0.005 = +5.99 / +1.31 / +4.39pp；−0.005 = +2.12 / +3.04 / +4.13pp。三个种子全为 G_corr 领先。

## 三、类别与 SNR 集中度

**复相关（S1_corr−S1）的增益集中在哪些类？**
- 增强后 CFO=±0.005 处增益最大的类是 **ASK/AM 类**：8ASK(2) +25~34、4ASK(1) +24~32、AM-DSB-SC(20) +27~29、AM-DSB-WC(19) +21、AM-SSB-WC(17) +15~20；其次 16QAM(12) +18~19、16APSK(8) +13~18、QPSK(4) +17~26。
- 但 clean 处的增益更分散（AM-DSB-SC、32QAM、256QAM、16APSK、128APSK 等），**不是只集中在 AM/ASK**。
- **受损类一致**：32PSK(7) 在所有条件下都明显受损（−8 ~ −15pp）；GMSK(22)、8PSK(5)、16PSK(6) 在多数条件下为负或近零。高阶 PSK 是复相关描述帮不上、甚至帮倒忙的类。
- 注意：类级增益的样本标准差很大（常见 ±10~30pp），说明**逐类效果种子间噪声大**，不宜据单一类别下结论。

**G_corr 与 S1_corr 的差异来自低 SNR 还是高 SNR？**
- 增强后，G_corr 相对 S1_corr 的优势**几乎全部来自高 SNR（>0dB）**：CFO=±0.005 时 low(≤0dB) 差异 ≈ 0（−1.7 ~ +0.6pp），high 差异 +2.1 ~ +10.4pp。
- 同理，S1_corr 相对 S1 的 +9.5pp 也**全部来自高 SNR**（low ≈ 0，high +13.8 ~ +18.3pp）。

**一句话**：复相关 × SSM 的 OOD 频偏增益是「高 SNR 下、跨 ASK/AM/QAM/APSK 多类、但高阶 PSK 受损」的现象，不是少数类或低 SNR 的偶然。

## 四、结论口径（观察 / 解释 / 机制分层）

**不再使用**的表述：①「clean 收益是 SSM 特有」；②「G 上复相关已被增强替代」；③「SSM 获得了独特的频偏补偿能力」。

改为分层：

1. **观察（可靠）**
   - 无增强时，corr 的 clean 配对差在 SSM 上为正（S1_corr−S1 = +1.86pp，3 seed 全正），在 G 上为负（G_corr−G = −1.37pp，3 seed 全负）。这是两个骨干各自基线上的配对差，**不构成「复相关天生只帮 SSM」的机制结论**。
   - 增强后，corr 对 G 的边际收益缩小（clean +1.9pp、CFO +1.4~2.1pp），但**未被完全替代**；corr 对 SSM 在增强范围外的 ±0.005 仍有 +9.5pp（3 seed 全正）。
   - 增强后，G_corr 在 clean 与全部测试频偏上绝对领先。

2. **可能的解释（未验证）**
   - 注意力骨干能把增强学到的频偏不变性外推到 2.5×（±0.002→±0.005）甚至 10×（±0.02）范围；SSM 骨干这种外推明显更差（S1 在 ±0.005 掉 14.3pp、±0.01 掉 21.9pp）。复相关描述对 SSM 的 OOD 掉点有大幅补偿，**但这只是「描述补偿了 SSM 的外推弱点」的描述性解释，不是已证明的电磁/状态机制**，不称为「频偏补偿能力」。

3. **机制（未证明）**
   - 复相关描述为何对 SSM 的补偿远大于对 G（+9.5pp vs +1.5pp），是否与复对角状态更新、选择器门控或 token 融合有关，本复核未做因果验证。

## 五、方向判断（对照决策表）

按「绝对性能 + 逐种子一致性」标准：

- **G_corr（CFO 增强的 attention + 复相关）在 clean 和主要频偏范围持续领先，逐种子方向一致** → 对应决策表第一行：**将 G_corr 作为强基线，当前 SSM 结构（S1 / S1_corr）归档为基线，不再作为主线。**
- S1_corr 未在任何连续频偏范围或明确任务条件下稳定占优（增强后处处落后 G_corr）；corr 对 SSM 的 +9.5pp 是「相对较弱自身基线」的增益，不构成绝对占优。
- 复相关 × SSM 的强补偿（+9.5pp OOD、全部高 SNR）作为**记录在案的观察**保留：若未来开发出本身 OOD 外推更强的 SSM 变体，再检验该交互是否仍有叠加价值；当前不必为这一现象扩展结构。

**下一步建议（不新增训练）**：本复核已闭环；方向层面的结论是「attention+corr+CFO 增强」性价比最高。若继续电磁专用骨干方向，应另起协议，验证 corr 描述与**更强 OOD 外推的 SSM 变体**（而非当前 S1）的组合，而非在现有 S1 上继续堆描述。
