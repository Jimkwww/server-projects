# 实验协议与实现定义

## 1. 研究问题与首轮范围

验证固定复数 SSM 能否作为可用骨干、输入选择是否有价值、物理描述是否有附加收益。最重要的机制比较为 **S2 vs S1**。

主实验是 5 模型 × 3 种子 = 15 个无专项频偏增强 run。先跑 seed17，确认可训练后完成 42、2026。S2_concat 是小规模机制补充对照，并不替代四个主模型。

历史 G 的 OA≈0.3869 仅作为背景，不能用它代替本轮 G。数据、训练或结构不同就不能硬对齐数值。

## 2. 网络定义

原始 `[B,2,L]` → 每 8 点一个 token → 实数 Linear(16,176) → 6 个 pre-norm block → LayerNorm → token 均值 → Linear(176,24)。要求 L 能被 patch 整除，无 padding。

Block：`x + mixer(LN(x))`，然后 `x + FFN(LN(x))`。默认 FFN 扩展 4 倍、GELU、dropout=0。这些外围设置需在服务器核对历史工程；不是已知的旧配置。

候选默认：P=128、选择器 hidden=64、无显式位置编码、单向扫描；每层每样本从零状态开始。SSM 的顺序性来自递推；G 是否需要历史位置编码必须审计，不得为方便而删去旧 G 的关键结构。若需要不同位置编码，明确属于模型配置差异，并补充统一外围的控制实验。

状态模块：

```
v_n = B u_n
h_n = a_n * h_(n-1) + g_n * v_n
y_n = gain * Re(C h_n) + d * u_n
a_n = exp(-softplus(raw_alpha) * delta_n) * exp(j theta)
```

B/C 为复数可训练矩阵，直通 d 为实数逐通道系数。gain 默认固定为1，不随训练变化。所有复数参数按2个实数标量计数。

- S0：delta=softplus(raw_delta)，g=1，参数可训练但不随 token 变化。
- S1：selector([u,0,0,0]) 输出 delta 修正和写入 logit。
- S2：selector([u,p]) 输出相同两种参数。
- 选择器：Linear(D+3,H) → SiLU → Linear(H,2P)。delta=softplus(raw_delta+修正)，g=sigmoid(logit)。
- S1/S2 选择器同形、同初始化、同标量参数量。S1 的3个附加输入槽为0，对应第一层3H个权重在前向无效；报告“分配参数量完全一致”，不要说有效自由度完全一致。当前每层相差192个有效输入权重，仅需在强机制结论前进一步用宽度补齐的特征选择器复核。
- S2_concat：同样的物理描述先经无偏置 Linear(3,D) 映射，加到初始 token；各层选择器不直接接收 p，但可以通过 token 间接使用它。该加法等价于一种受约束的拼接线性融合，不能声称信息完全不能影响门控。

S0 的初始 g=1，S1/S2 初始 g约0.5。这是选择模块初始化差异，不能仅由 S1/S0 的差值证明“动态性”独有贡献。若需严格拆解，增加固定g=0.5的 S0 控制并另开实验记录；首轮不自动混入主表。

初始化：衰减时间尺度2～128 token对数均匀，基础旋转角均匀分布于[-pi,pi)。alpha 与 delta 的乘积控制衰减，不把二者分别当成可辨识物理参数。

## 3. 物理描述

每个 token 计算 `log(E+eps), Re(r), Im(r)`。E 为块内平均复功率。r 只使用该块内部 Q-1 对相邻采样，不跨 token、不跨样本、不循环补边。这样第一块与其他块的边界规则一致。

该规则对应原方案的局部窗口定义的一种明确实现：相关窗口不包含每块的第一个采样位置。与“允许跨块的相邻对”不同，比较时不能混用。

统计标准化仅从固定随机训练子集拟合，seed固定0，最多8192个样本，独立于模型训练种子；不读取 val/test。保存均值、标准差和子集索引hash。描述由实际增强后的IQ重新计算，绝不把真实注入频偏当作输入。

相位变换保持 E/r；频偏使 r 乘 exp(j2pi f)。这是描述的变换规律，不代表网络或 patch embedding 已等变，也不意味着 r 就是准确频偏估计。

## 4. 数据与优化

已知必须沿用：RML2018A 24类、cls_dev划分、50 epoch、lr=3e-4、fp32、种子17/42/2026。

待审计的候选默认：batch128、AdamW、weight_decay=.01、betas=(.9,.999)、eps=1e-8、cosine、无warmup、clip_grad_norm=1、无额外增强、无输入归一化。这些不能被当作之前已确定的参数。服务器应先用旧工程的实际设置修订 `resolved.json`。

同一 campaign 的各模型共用数据、训练设置、batch、checkpoint选择、预处理。数据shuffle使用独立生成器，各模型同seed具有同样的样本顺序。频偏增强使用独立生成器，避免模型初始化/dropout改变增强抽样；随机状态随checkpoint保存。

正式训练入口要求审计记录，smoke结果明确标识且不纳入汇总。验证集OA选最佳epoch，平局保留最早；Macro-F1和分SNR指标来自该同一个checkpoint，不能各自挑最佳epoch。

val用于本轮模型开发与诊断。若有独立test，只在结构/网格/选择规则冻结后进行一次最终评估，不依据test结果调参。测试划分缺失时如实报告，仅做val，不伪造划分。

## 5. 实验矩阵

| 批次 | 模型与种子 | 内容 |
|---|---|---|
| A1 | G/S0/S1/S2/S2_concat，seed17 | 正式50epoch首种子，检查训练曲线和异常 |
| A2 | 同5模型，seed42/2026 | 完成15个clean run |
| B | A中全部run的最佳checkpoint | 干净、相位、频偏、逐SNR |
| C | 各模型seed17最佳checkpoint | 统一设备的延迟、吞吐、显存与序列长度 |
| D（条件扩展） | G/S0/S1/S2，3种子 | 相同频偏增强条件，另开campaign，共12个run |

D在频偏敏感性明确、拟进一步比较鲁棒性时执行。先从合法的开发集网格确定增强幅度并冻结。一个候选值是绝对归一化频偏≤.002，**并非已确认适用RML2018A的范围**。对所有模型相同分布，相同seed顺序；用本轮独立aug RNG。S2_concat若涉及主结论，再补齐增强对照。

未增强与增强结果分表，不能混为同协议均值。D不是首轮A的阻塞条件。

## 6. 频偏和相位评估

频偏：`s'[m] = s[m] exp(j 2pi f m)`，f为cycles/raw sample，即Delta f/fs；phase为弧度。施加在输入IQ上（若数据已做样本RMS归一化，它与此单位幅度旋转可交换）。

默认候选频偏网格为0、±.001、±.002、±.005、±.01。运行前必须检查占用带宽/混叠与标签合理性；不知道采样率时不标Hz。默认不是批准过的科研扰动范围。

每个样本固定同一f、从m=0开始累积，便于模型间配对。固定相位网格0、pi/4、pi/2、pi、3pi/2。默认不是随机相位平均试验。保存原始样本ID与预测（开启--save-predictions）。

同时报告绝对OA/F1与相对clean下降；逐seed和逐强度分析，不挑最有利点。门控诊断只作为辅助证据，不能据此声称频偏补偿。

## 7. 效率口径

固定同一GPU、精度fp32、eager执行、TF32关闭。先验记录环境与是否空闲，避免其他任务争用。

batch1延迟：warmup50，1000次，每次GPU同步，记录均值/p50/p95；吞吐另用连续迭代后统一同步计时。固定batch64，所有模型相同；如有OOM则全组降batch重测，不让不同batch直接相除。

计时覆盖IQ已在GPU上的完整模型（包括物理描述）；不包含读盘、DataLoader、H2D。显存为PyTorch peak allocated/reserved；CPU不伪报GPU显存。训练峰值显存另外在history中记录。

长度候选256/512/1024/2048/4096采样点。超训练长度只测计算开销，不代表精度泛化。若使用learned位置编码，代码会跳过不同长度，不插值冒充同模型；需要另建固定位置策略的效率对照并清楚标注。

parallel是原生Torch并行前缀 O(N log N)工作量/O(log N)阶段；serial是Python递推正确性参考。当前效率结论仅针对这份实现。不得声称已具备融合Mamba/S5内核的线性工作效率。

## 8. 停止与归因

NaN、梯度非有限、状态爆炸、门控长期饱和、训练近随机等先排障，不继续烧完所有种子。保留失败日志与诊断。

数据或原Global协议无法确认：停止正式训练并明确缺失信息，不重新随机划分来凑结果。

S1有效S2无稳定附加收益：结论只能支持一般选择，不支持物理辅助选择。
S2有效：必须同时查看S2_concat、参数/优化/干净性能及扰动曲线。
S0/G差异同时受方向性、参数量及实现影响，不能直接归因于复数状态。
多个种子均值/标准差是描述性证据，不把3种子说成统计显著。
