## 2. 核心想法

把一维token序列划分为若干连续、互不重叠、长度不同的窗口。窗口内进行双向自注意力，窗口间在该层不直接注意。下一层循环轮换窗口长度列表并从序列起点重新分区，使新窗口跨越旧边界。

区别于多头多尺度分支：同一层同一token只属于一个窗口，所有头默认使用同一分区；多尺度信息主要通过多层传播融合。
区别于token shuffle：保持token时间顺序不变，不重排输入和输出。
区别于patch merging：本轮不合并token，每层输入输出均为[B,128,176]。

暂用工程名称 `unequal_window_cyclic`，不使用“首创”“保证全局交互”等未经证明的表述。

### 2.1 精确定义

设长度列表 W=[w0,...,w(K-1)]，所有元素为正整数且sum(W)=N。第一版每个元素互不相同，但“互不相同”本身也是未验证的设计选择。

层编号l从0开始，轮换步长s=1：

    r = (l*s) % K
    W_l = W[-r:] + W[:-r]  if r > 0 else W

例如[3,5,7,13]依次变为[13,3,5,7]、[7,13,3,5]、[5,7,13,3]。
以W_l的前缀和生成半开区间[start,end)，每个窗口覆盖原始token索引上的连续区间。

允许注意矩阵A_l[i,j]=1，当且仅当i和j处于同一窗口；否则为0。所有对角线必须为1。本任务是离线分类，默认非因果注意力。

注意：循环的是“窗口长度排列”，不是将信号首尾连接。不得引入最后一个token与第一个token之间的额外环形窗口。

### 2.2 网络主体

使用现有Global模型作为主干，只替换注意力连接范围；保持patch embedding、位置编码、QKV与输出投影、归一化位置、MLP、残差、pooling和分类head完全一致。

默认N=128、C=176、depth=6、heads=4、MLP ratio=4。所有窗口共享该层QKV和输出投影参数，不为不同长度窗口新增独立权重。各层仍拥有各自的参数，与Global一致。

保留Global已有的位置编码，不能在每个窗口内把绝对位置重置为0。若当前实现依赖特殊位置偏置，先说明如何保持一致；不要同时新增不同的位置编码方案。

## 3. 要验证的假设

H1：相比同一不等长分区始终固定，跨层轮换能改善信息交流和分类表现。
H2：相比等长移位窗口，在相近注意力预算下，不等长窗口有更好的效果或精度—开销折中。
H3：相比Global，局部约束与多种交互跨度可能改善泛化，或以更少注意力交互保持接近的准确率。

以上均可失败。结构可达不代表模型一定使用了远处的信息，理论交互量下降也不代表墙钟速度提升。不能将结果差异预先解释为某类信号特征被捕获。

## 4. 训练前先做连通性分析

对每组窗口规则生成各层分区和A_l，并按层顺序计算输入依赖关系。不能只把所有层的边取并集后判断无向图是否连通。

定义R0=单位矩阵，R_l[i,j]=1表示第l层输出token i存在依赖原始输入token j的结构路径。递推采用布尔矩阵乘法：

    R_next = (A_l.astype(int64) @ R.astype(int64)) > 0

A_l包含对角线，因此已覆盖残差的自连接。逐层二值化，避免多层路径计数累积溢出。该分析针对encoder token间传播，不把最终全局平均池化当作encoder全局交互。

每层输出：

- 各token可达输入数量；最小值、均值、最大值及除以N后的比例。
- 有多少输出token覆盖全部输入。
- 每个输出token首次覆盖全序列的层数（若没有则注明）。
- 每个输入token能影响多少输出token，避免只观察接收侧平均值。
- 永久边界、分区图、A_l热图和最终R热图。

可扩展分析到12层了解传播所需深度，但主训练保持6层。仅根据连接分析可以预注册至多一个修订schedule；不得为了挑选高验证分数不断更换schedule。未达到全局可达不自动判定结构失败，应如实报告。

## 5. 第一轮配置与对照矩阵

### 5.1 主窗口列表

使用W_A=[4,8,16,24,32,44]，sum=128、K=6、sum(w²)=3872。
这是手工初始列表，不声称幂次、素数或最优数列。它提供六种尺度，与六层轮换对应。保持128个token，仅改变连接范围。

### 5.2 必做第一阶段

| ID | 注意力 | 层间变化 | 目的 |
|---|---|---|---|
| G | 全局 | 无 | 相同主干和训练流程的准确率基准 |
| U-F | W_A不等长窗口 | 所有层固定W_A | 排除仅使用不等长窗口的影响 |
| U-C | W_A不等长窗口 | 每层右轮换1位 | 待验证方案 |
| E32-S | 等长window=32 | 非移位/移位16交替 | 相近注意力预算的窗口对照 |

E32-S必须使用标准边界mask语义，禁止序列两端因循环roll发生额外注意。记录其实际分区、有效交互量和实际计算形状。128×32=4096是未考虑边缘mask的窗口矩阵元素数，不能把它等同于全部有效交互数。

若有资源，再加入E8-S（window=8、shift=4交替），用于连接原Swin的窗口尺度；它仍使用无merge的Global主干，不能与原分层Swin混为一谈。

G在配置、种子、代码和数据完全一致且日志完整时可复用已有run；否则重跑。本轮所有主对照从头训练50ep。已有“分层Global”实验继续保留为另一条结构分析支线，不计入这四组的严格单因素比较。

U-F和U-C具有完全相同的窗口长度集合、参数量和理论窗口交互预算，是主要因果对照。U-C与E32-S只称“近似注意力预算”，不能称严格同FLOPs。

## 6. 实现方式与必要检查

### 6.1 先实现参考版本

预生成每层[N,N]允许矩阵，在原Global注意力中以mask限制窗口。优先用现有注意力API，确认其布尔mask True表示允许还是屏蔽，不凭经验假设。

密集mask版只用于正确性和第一轮精度验证，不据此宣称稀疏加速。mask缓存为buffer并跟随device，检查混合精度、训练与eval路径都使用相同分区。

### 6.2 再实现分窗口版本

共享投影后按连续区间切分Q/K/V，各窗口独立计算attention，再按原位置拼接输出。需要实测效率时再优化分组或padding。不同长度的小kernel调用可能使实际速度慢于Global。

### 6.3 必做正确性检查

1. 每层窗口不重叠、不遗漏，总长度128；token顺序不变，输出形状正确。
2. 单窗口W=[128]在权重相同、dropout关闭时与Global输出一致，梯度在合理浮点误差内一致。
3. dense-mask版与分窗口版相同权重下输出、输入梯度和关键参数梯度一致；先FP32，再检查训练精度下的数值稳定性。
4. 对单个block，改变窗口外输入不应影响窗口内输出（排除额外跨token算子）；多层后允许沿R传播。
5. 从参数梯度确认QKV、投影、patch embedding和head参与训练，无NaN/Inf，无全屏蔽行。
6. 小样本训练能够下降loss，用于排除训练管线失效；该检查不是泛化性能证据。
7. 若使用CLS token，不能不加说明地给予全局连接。以已有pooling为准；有CLS时先明确其规则，避免跨窗口通路由CLS主导。

## 7. 训练与选择协议

### 7.1 单种子筛选

从现有配置选一个固定种子，四组用同一数据划分、batch size、优化器、学习率计划、weight decay、增广、loss和评估频率。记录所有dropout、attention dropout及drop path，而非只记录一个dropout字段。

能共享的初始化使用相同初始state_dict，记录缺失和新增键。注意复现数据shuffle与随机增广；不要求不同结构数值执行完全确定，但需记录非确定性设置。

每个run固定50ep预算；按验证OA选择best checkpoint，平局规则事先确定。记录最后epoch和best epoch，不只保留最高值。记录对应checkpoint的macro-F1；若历史F1定义不明，核实后再比较。

### 7.2 多种子确认

首先完成四组单种子对照。若U-C相对U-F和E32-S呈现值得跟进的趋势，或准确率接近Global且交互预算明显更低，将四组补到相同的3个种子。种子列表在追加训练前固定，例如沿用项目种子体系选择三个值。

报告各seed结果、均值、样本标准差和同seed成对差值。3个种子只能提供初步稳定性证据，不把微小均值差异直接称为显著。若筛选结果明显无优势，先诊断实现、连通性与曲线，再决定是否追加，避免全组合扩张。

统一配置是受控比较，不代表每种架构已达到最优。需要调参时，给关键对照相同的少量搜索预算，并另列结果，不能只调新模型。

### 7.3 数据和测试集约束

固定train/val/test清单或哈希，核实预训练数据与测试集的隔离方式。不要通过测试集选择窗口、种子、epoch或超参数。结构与配置确定后，才统一评估保留测试集；若没有独立测试集，明确所有结论只是验证集结论。

若存在按SNR或类别的元数据，输出分SNR OA、每类召回与F1、样本数及混淆矩阵。不猜测数据集具备哪些元数据。

## 8. 理论预算与实际性能分开报告

每层每个head的注意力矩阵元素数：Global为N²=16384；U-F/U-C为sum(w²)=3872，约为Global的23.6%。这不包括QKV、输出投影和MLP，不等于整网计算量或延迟降低76.4%。

在结构显现价值后测量：参数量、FLOPs/MACs口径、训练step时间、推理延迟、吞吐、峰值显存。保持同一GPU、软件版本、精度、batch、attention backend和编译设置。

区分batch=1延迟与训练batch吞吐；预热、设备同步后多次测量并报告中位数及波动。避免与其他占用GPU的任务并发测速。分别记录dense-mask和真正分窗口实现，不混用结果。

“保持相近精度”的容忍范围要在看最终测试结果前确定；默认报告完整精度—延迟—显存数据，不擅自定义达标线。

## 9. 第二阶段：必要时才做的消融

在U-C有支持性结果后按优先级进行，暂不全排列。

1. 方向与起始相位：右轮换1位对比左轮换1位或一个固定起始相位，判断是否依赖偶然的位置安排。一个token并不保证轮换一周期后恰好经历每一种窗口长度，要实际统计。
2. 数列形状：可用W_B=[3,7,13,23,35,47]，总和128、平方和4190，作为不规则奇数列表；它不是全素数列表，且预算比W_A高约8.2%，结果不可归因于“素数优势”。
3. 等长与不等长：尽量匹配交互预算并记录边界处理差异；已有E32-S为初始对照。
4. 随机排列：仅当需要判断循环规则是否特殊时加入。先用运行前固定、可复现的逐层随机排列，不要第一版就每个batch随机。

每个新列表先进行连通性分析，再训练。若探索轮换步长s，记录周期K/gcd(K,s)；较短周期可能只遍历少数排列。不要宣称遍历全部排列必然实现全局可达。

## 10. 第三阶段：接回预训练

仅在监督实验完成后，为选定新结构训练匹配的MAE encoder，并与其从头训练结果比较。不要把Global或原Swin的预训练权重直接迁移后当作该结构预训练效果。

至少比较Global从头、Global预训练全微调、新结构从头、新结构预训练全微调。尽可能对齐预训练数据、步数、遮挡方式和解码器预算；冻结线性探测可作为诊断但不能代替全微调评价。

特别注意：若现有MAE删除masked token并压紧可见序列，直接在压紧序列上套连续窗口会改变“原时间轴窗口”的定义。必须明确窗口由原始patch索引还是压紧索引划分，不能悄悄换语义。使用mask token保留网格也会改变现有预训练流程，应单独记录，处理空窗口与重构loss的索引映射。

先固定一种匹配的预训练实现，再单独研究遮挡粒度或比例。监督结果不佳时，不默认用更大预训练预算补救。

## 11. 如何解释结果

| 结果模式 | 可以支持的结论 | 不能推出的结论 |
|---|---|---|
| U-C稳定优于U-F | 对该列表和配置，边界轮换有益 | 任意轮换都有效 |
| U-C与E32-S接近 | 未显示不等长方案明显优势 | 多尺度注意力永远无效 |
| U-C优于E32-S但低于Global | 在窗口方案中有收益，仍有全局差距 | 已超过Global |
| U-C接近Global且实际提速 | 有精度与效率折中价值 | dense-mask理论节省就等于提速 |
| 可达范围充分但性能仍差 | 结构路径存在不足以保证可学习性 | 连通性分析无用 |
| 仅一个seed或单个SNR有收益 | 初步或局部趋势 | 整体稳定提升 |
| 监督有效而MAE收益小 | 需检查预训练目标与结构匹配 | encoder结构已失败 |

若U-C胜出，需要同时观察训练/验证差距、各SNR和类别表现，而不是只展示best OA。best epoch早并不能单独证明过拟合，应检查同checkpoint训练与验证曲线。
