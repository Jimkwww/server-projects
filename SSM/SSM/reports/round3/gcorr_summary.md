# G_corr 对照结果（同描述、不同骨干）

> G_corr = G（注意力 + 正弦位置编码）+ 仅复相关融合（能量维置零，与 S1_corr 完全一致）。3 seed × 50ep，order B 评估。

## Clean 与 CFO（order B，均值）

| 模型 | clean OA | CFO=+0.005 | CFO=−0.005 |
|---|---|---|---|
| G | 0.3869 ± 0.0056 | 0.1787 | 0.1763 |
| **G_corr** | **0.3732 ± 0.0050** | **0.2170** | **0.2035** |
| S1 | 0.3813 ± 0.0076 | 0.2510 | 0.2625 |
| S1_corr | 0.3999 ± 0.0057 | 0.2974 | 0.3068 |

## 配对差（逐 seed / 均值，order B）

| 对比 | clean | CFO=+0.005 | CFO=−0.005 |
|---|---|---|---|
| G_corr − G | −1.44 / −1.25 / −1.41（**−1.37**） | +3.81 / +3.53 / +4.13（**+3.82**） | +1.47 / +2.76 / +3.94（**+2.72**） |
| S1_corr − S1 | +0.48 / +3.01 / +2.08（**+1.86**） | +2.18 / +4.65 / +7.12（**+4.65**） | +0.42 / +4.42 / +8.46（**+4.43**） |
| S1_corr − G_corr | +1.60 / +3.49 / +2.92（**+2.67**） | +6.44 / +7.98 / +9.71（**+8.04**） | +8.24 / +11.70 / +11.06（**+10.33**） |

## 结论

1. **复相关的 CFO 鲁棒性收益是通用的**：G_corr 相对 G 在 ±0.005 下 +2.7~+3.8pp（3 seed 全为正），S1_corr 相对 S1 +4.4~+4.7pp。两个骨干都因复相关融合更抗频偏。
2. **复相关的 clean 收益是 SSM 特有的**：S1_corr−S1 = **+1.86pp**（3 seed 全正）；G_corr−G = **−1.37pp**（3 seed 全负）。复相关融合在 G 上以 clean 精度为代价换鲁棒性，在 SSM 上二者兼得。
3. **SSM+复相关仍有额外价值**：控制描述相同（都仅复相关），S1_corr 相对 G_corr 在 ±0.005 下高出 **+8.0~+10.3pp**（clean 也 +2.67pp）。这不能归因于骨干本身的 clean 基线差异（G 0.3869 vs S1 0.3813），而是 SSM 与复相关描述在频偏下的协同更强。

综合：**既有通用复相关融合收益，也有复相关×SSM 的额外协同**。后者是否会被简单 CFO 数据增强替代，由增强对照（step ③）决定。
