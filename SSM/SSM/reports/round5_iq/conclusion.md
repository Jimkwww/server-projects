# Round-5 复数前端公平对照与 IQ 辅助支路实验：最终结论

**一句话结论：两条实验线均未产生"突破性正面收益"，但得到了清晰的机制性结论——①在匹配初始化 + 共享主干 + 相同优化器的公平条件下，复数前端与实数前端无可测差别（修正了 Round-4 把"复数前端 −4pp"归因于复数的误读，实为初始化尺度 + bias 混杂）；②bias 有无是 Line A 唯一显著且方向一致的因素（+2.5pp）；③辅助支路的相关 readout（Q_corr）有效（clean 超 S1 +2.5pp、超 S1_corr +1.65pp），但大 CFO 下退化；④更自由的 2×2 实递归（R_corr）相对复递归无额外收益且慢约一个量级。**

以下按 6 个判定问题回答，严格区分「观察」（数据事实）、「解释」（有依据的推断）、「未证实机制」（不能声称）。所有 OA 差均为百分点(pp)，即 OA 小数差 ×100（均值与样本标准差 ddof=1 同步换算），3 个种子不做独立样本处理。

---

## Q1 公平条件下，复数前端是否优于/劣于实数前端？

**否——无可测差别。**

- **观察**：C0 − R0 = +0.27 ± 0.23pp（clean）；Cb − Rb = +0.18 ± 0.27pp（clean）。三种子方向不一致，量级小于种子波动。CFO/phase 各条件同样无系统性差异（CFO-0.001 +0.14、CFO-0.002 +0.42/−0.11、CFO-0.005 +0.05/−0.61、phase 均 <0.3pp）。
- **解释**：在「等价实矩阵方差对齐 `nn.Linear`=1/48 + 共享 S1 主干 + 相同优化器/lr + 绑定权重聚合梯度」的公平条件下，"复数绑定前端 vs 实数自由前端"这一结构性因素本身不带来可测差异。因此 Round-4 观察到的 `B_front − S1 ≈ −4pp` **不能归因于"复数"**，而应归因于 Round-4 复数前端用了 `ComplexLinear` 的 `N(0,1/in)` 初始化（实/虚各 1/16 方差，等价实矩阵方差 = `nn.Linear` 的 3×）以及 bias/结构混杂（见 ERRATA）。
- **未证实**：不能说复数前端与实数前端"严格等价"——绑定 vs 自由仍是不同的参数化/梯度空间，只是在本冻结配置下不可区分。

## Q2 bias 是否显著？

**是——bias 是 Line A 唯一显著且方向一致的因素（+2.5pp）。**

- **观察**：Rb − R0 = +2.52 ± 1.24pp（clean）；Cb − C0 = +2.44 ± 0.78pp（clean）。三种子一致为正（Rb−R0 各种子 +1.67/+3.94/+1.96pp；Cb−C0 各种子 +1.98/+3.33/+1.98pp）。CFO 各点也一致为正（+1.16~+3.12pp），phase 一致为正（+2.09~+2.47pp）。
- **解释**：前端 bias 为后续 S1 提供可学习的直流/均值分量。无 bias 时，输入经 order-B 联合 max-abs 归一化后，前端线性映射缺失平移自由度；补上 bias 后清洁 OA 稳定提升。这与 R0/C0 的 clean OA（0.38）明显低于 Rb/Cb（0.41）一致。
- **未证实**：bias 增益的精确机制（是直流分量本身，还是它对优化/表示的作用）未证实。

## Q3 均值 readout 的辅助支路（Q_linear）是否带来增益？

**否——完全等于 S1。**

- **观察**：Q_linear − S1 = +0.00 ± 0.12pp（clean），各 CFO/phase 也 ≈0（+0.36/−0.07/+0.54/+0.33/+0.09pp）。诊断显示 Q_linear 的支路时延参数 tau 基本保持初始化（2~120 对数均匀），theta 基本保持 `linspace`（−180°…136°），只有 |b| 与 W_f 有学习。
- **解释**：patch 内均值 readout 抹掉了时域相位/频率结构，且 W_f 零初始化使支路参数在梯度时序上起步极慢（step1 支路梯度恒为 0），导致支路实际退化为 S1。这是"readout 设计 + 初始化耦合"造成的无效，不证明"辅助支路必然无效"。
- **未证实**：不能由 Q_linear 的失败推断所有均值型辅助支路无效。

## Q4 相关 readout（Q_corr）是否优于均值 readout？

**是——Q_corr 显著优于 Q_linear（clean +2.54pp），且是全表最强的新变体。**

- **观察**：Q_corr − Q_linear = +2.54 ± 0.53pp（clean），三种子一致正；CFO 各点更明显（+2.41~+4.06pp），phase 一致正（+2.26~+2.47pp）。Q_corr clean OA = 0.4544，超过 S1（0.4290，+2.5pp）与 S1_corr（0.4379，+1.65pp）。per-SNR 看，增益主要在高 SNR（Q_corr 高 SNR 0.6626 vs S1 0.6246，+3.8pp；低 SNR 0.1705 vs 0.1621，+0.84pp）。
- **解释**：patch 内相邻复相关 `r = Σ q[t]·q[t−1]^*/(‖q[t]‖·‖q[t−1]‖)` 捕捉了调制符号间的相位/幅度跳变结构。class 分析显示 Q_corr 在幅度相位联合调制类显著提升（16QAM 0.263→0.325、32QAM 0.100→0.211、64QAM 0.077→0.126、256QAM 0.104→0.193、16APSK 0.451→0.513、32APSK 0.394→0.464），与"相关特征对高阶 QAM/APSK 判别性强"一致。
- **未证实**：相关特征 = 物理调制结构的具体对应关系未证实。

## Q5 相关辅助支路（Q_corr）相对 S1_corr 基线如何？CFO 下如何？

**clean 上 Q_corr 更好（+1.65pp，一致正），但大 CFO 下显著更差（−4.84pp）。**

- **观察**：clean Q_corr − S1_corr = +1.65 ± 0.10pp（三种子一致正）；但 CFO-0.005 时 Q_corr − S1_corr = **−4.84 ± 0.55pp**（显著负）。CFO 绝对 drop 对照：+0.005 下 S1_corr 掉 5.69pp、G_corr 掉 4.09pp、G 掉 3.60pp，而 Q_corr 掉 10.84pp、R_corr 掉 9.91pp、S1 掉 14.31pp。
- **解释**：Q_corr 的增益来源（相邻复相关）对 CFO 引起的相位漂移敏感——CFO 使相邻符号间的相位差整体偏移，破坏相关特征；而 S1_corr/G_corr 的融合结构在大 CFO 下更稳健。这与本项目 MultToken 发现的"附加频偏极敏感"现象同源（观察，非本轮证实）。
- **未证实**：Q_corr 在大 CFO 下的退化是否**必然**由相关特征的相位敏感性导致，需单独消融（例如对相关特征做相位对齐/差分）。

## Q6 更自由的 2×2 实递归（R_corr）是否优于复递归（Q_corr）？

**否——无额外收益，且慢约一个量级。**

- **观察**：Q_corr − R_corr = +0.19 ± 0.45pp（clean），方向不一致；各 CFO/phase 无系统性差异。效率上 R_corr batch1 延迟 43.96ms vs Q_corr 3.28ms（13×），batch64 吞吐 1264 vs 7868 sps（6×），因其用显式 1024 步循环而非 parallel_scan。
- **解释**：把复递归展开为更自由的 2×2 实状态（A_k 一般矩阵 + 谱范数<1 约束）在本配置/数据规模下未带来额外表示能力。诊断显示 R_corr 的 A_raw 谱范数仍≈1.0（基本保持旋转矩阵 init），rho 均值≈0.875，说明其自由度未被有效利用。
- **未证实**：不能说"复递归总是等价于/优于实递归"，仅当前配置下无差别。

## CFO / 相位鲁棒性对照（补充观察）

**全局相位旋转**：所有变体在 phase 0/π/4/π/2/π/3π/2 下 drop 均 <1.3pp（order-B 先扰动后归一化，全局相位对幅度结构影响极小），无模型间显著差异。

**大 CFO（±0.005）drop 排序**：G_corr(3.5~4.1) < G(3.6~3.8) < S1_corr(4.3~5.7) < R_corr(9.9~10.6) ≈ Q_corr(10.8) < Q_linear(10.6~12.3) < S1(12.9~14.3) < R0/C0(13.7~14.0) < Rb/Cb(14.3~15.8)pp。辅助支路（Q/R）相对主线 S1 在大 CFO 下更稳健（掉 ~10pp vs 14pp），但仍远不如 S1_corr/G_corr（掉 ~4-6pp）。

## 基准定位（复用历史结论不变）

- clean 最高仍为 **G_corr = 0.4609**；Q_corr = 0.4544 是接近 G_corr 的新高，但其 CFO 鲁棒性（掉 10.8pp）明显弱于 S1_corr/G_corr。
- CFO 鲁棒性最强仍为 **G/S1_corr/G_corr**（大 CFO 掉 3.6~5.7pp）。
- Line A 的 R0/C0/Rb/Cb 无论 clean（0.38~0.41）还是 CFO 鲁棒性均不构成对既有基线的挑战。

## 建议

1. **归档 Line A**：复数前端在公平条件下无独立价值；bias 的 +2.5pp 效应已被 Rb/Cb 记录，可作为后续"前端 bias"的默认建议。
2. **Q_corr 值得记录但不建议直接采纳**：其"相邻复相关"readout 是有效设计（clean +2.5pp over S1），但大 CFO 退化（−4.84pp vs S1_corr）使其不适合作鲁棒前端；若继续，需先解决相关特征对 CFO 的敏感性（相位差分/对齐）。
3. **归档 Q_linear（无效）与 R_corr（无额外收益且慢 13×）**。

## 不声称边界（重申）

- 不声称复数隐藏状态 = 物理状态；不声称严格等变或 CFO 补偿。
- 全部结论仅限当前冻结配置（RML2018A cls_dev、patch=8、width 176/88、depth 6、state 128、order-B）；未用 test；未做超出任务书的额外调参/分支。
