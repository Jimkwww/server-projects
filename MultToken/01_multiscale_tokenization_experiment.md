# 实验方案一：面向电磁信号的多尺度 Token 表示

版本：v1.0；日期：2026-09-21。状态：研究设计，尚未实施或获得结果。

## 1. 交给服务器 agent 的任务摘要

在当前可复现的 Global Transformer 基线上，保持主干、全局注意力、分类头及训练协议不变，独立比较原始 I/Q 切块、可逆块内变换控制、多尺度时间前端、小波包、小波和复数 STFT 等 token 表示。

本阶段只改变输入表示和必要的表示适配层，不引入对齐注意力，不恢复 Swin 分层和窗口实验，不将不同改动一次性叠加。先监督训练验证，再对少数候选验证自监督预训练。

用户目标不是强制逐点无损，而是：多尺度、多表征之间能够互补，合起来充分保留电磁任务需要的幅相和时序信息，且比固定 I/Q 切块更容易学习、泛化更好。重构是诊断，不是唯一优化目标。

当前文档不指定服务器路径、数据集版本、已完成运行编号或“最新最优分数”。agent 必须从实际配置、日志和权重确认，不能把历史聊天里的数字或不完整消融解释当作复现依据。

## 2. 研究问题与可证伪假设

H1：固定采样点切块将物理尺度和采样条件绑定；多尺度表示可能改善跨符号率、采样率、带宽条件的迁移。

H2：保留复值响应的多尺度/频带表示，比仅保留幅度或功率更适合某些需要相位信息的任务。

H3：小波包等有组织的跨时间滤波与分带，能够在相近 token 数下提供比原始切块更合适的归纳偏置。

H4：收益可能只是参数、额外 token、滤波平滑或训练预算增加造成；必须用预算控制和简单前端排除这些解释。

不要预设所有电磁信号稀疏、周期重复或都适合小波。短片段、脉冲、宽带调制、多信号混合可能有不同结果。

## 3. 开始前必须完成的基线核验

输出 `baseline_audit.md`，记录：

- 数据集名称、版本、标签、SNR 范围、输入长度 N、I/Q 顺序、样本归一化和划分文件哈希。
- 采样率、符号率等元数据是否真实存在；不存在时不得编造 Hz、秒或符号单位。
- 原始切块长度 P、步长、padding、token 数 T、嵌入维度 D、层数、头数、位置编码和分类头。
- 优化器、学习率、调度、batch、训练步数、增强、随机种子、checkpoint 选择规则。
- 如有预训练：mask 单位/比例、编码器是否删除 token、解码器输入、重构目标及损失区域。
- 一次当前 Global 基线复现结果，与已有日志偏差及解释。无法复现时先修复，不扩大方法搜索。

数字例子只用于说明：若 N=1024、P=8、步长=P，则原始 token 数为128；实际实验以审计结果为准。

## 4. 统一接口与公平性

输入 `x: [B,2,N]`，或内部复数 `[B,N]`。所有 tokenizer 返回：

```python
TokenBatch(
    embeddings,        # [B,T,D]
    valid_mask,        # [B,T]
    time_center,       # [T] 或 [B,T]，样本坐标
    time_support,      # 支持区间/有效长度，包含滤波器实际支持
    scale_id,
    band_id,
    analysis_metadata, # 分解树、滤波器、频率响应、边界方式等
)
```

复系数优先用实部/虚部配对输入；不默认取模、功率化或只留正频率。普通实系数小波可对 I、Q 使用相同变换并保持配对；这与构造解析复小波不是一回事。

比较分两条报告轴：

1. 机制对照：相同主干、D、训练步数及尽量相同 T，清楚报告前端参数/计算差异。
2. 效率对照：比较实际延迟、吞吐、显存和性能的折中；如 token 增多，增加相应原始 I/Q token 数控制。不同预算的最优点不得直接解释成机制优势。

位置表示分组处理：原始基线保留原设置；结构化 token 比较“沿展平序列的原设置”与“时间中心+尺度/频带元数据”。后者是额外改动，必须做元数据开关消融。不能把不同频带展平后的编号直接当实际时间。

滤波器固定的收益与可学习的收益分开报告。样本级归一化协议保持一致；若每频带归一化，必须保留或另行记录能量尺度，避免偷偷删掉功率信息。

## 5. 方法定义

### T0：原始 I/Q 固定切块，主基线

沿时间每 P 点构成一个块，将 2P 维展平后投影至 D。复用现有实现，不重写基线以避免引入额外差异。

### T1：块内正交变换，控制组

在 T0 每个块内部，对 I 和 Q 分别做固定正交 Haar/DCT 等变换，保留所有系数，再接与 T0 同形状的线性投影；token 数不变。

此组不是主创新：若 z=A x，后接任意线性 W，则 W A 的函数族与原始线性投影相同（A 可逆时）。用吸收变换后的初始权重做前向一致性检查；独立随机初始化可能有优化差别，但不能据此声称引入了新物理信息。

### T2：多尺度时间滤波，简单强控制

采用三个固定长度、同中心网格的线性一维卷积分支；初始建议有效核长接近 P、2P、4P，按实现需要调整奇偶并记录。步长均为 P，输出约 T0 个时间位置。

各分支作用于 I/Q；先采用相同实系数滤波结构或明确的复线性结构，不对 I/Q 随意施加独立非线性后宣称保相位。沿通道拼接再线性映射至 D，保留相同 T。

对照单尺度卷积、同参数量普通卷积以及随机固定滤波器。可学习卷积的时间支持明确，但未经约束时不能解释成严格频带分解。

### T3：小波包 WPT，第一阶段重点候选

先使用固定小波包，避免同时学习滤波器和树结构。

建议顺序：Haar 深度 J=2；db4 深度 J=2；对验证集最好的波形基扩展 J=1、3。不要一开始枚举所有小波和深度。

实现步骤：

1. 对 I/Q 使用相同小波包树、边界处理和系数顺序。
2. 保留第 J 层全部 K=2^J 个叶节点；记录库的自然顺序与频率顺序，不能将二者混淆。
3. 每个叶节点沿其系数时间轴每 P 个复系数形成一个 token，映射至 D。
4. 每个 token 标记分支、深度、时间中心及实际分析支持。系数间隔为约 2^J 个输入样本，但支持长度还取决于滤波器长度，不能只按间隔计算。
5. 所有叶节点 token 合并后送入相同 Global Transformer。

在 N 可整除且采用临界采样、合适边界方式时：每叶约 N/2^J 个复系数，合计 N 个；每叶按 P 分组后总 T 约为 N/P。真实 padding/边界系数可能使其不同，必须记录实际值。

这个方案无需把完整树的所有层都输入。分支数增加、单分支序列缩短，总 token 数可保持接近基线。临界采样小波包对平移可能敏感，必须专门评估，不得宣传其天然平移不变。

补充候选 T3-M：完整混合深度树。如保留一条一级分支，另一条一级分支继续分成两条二级分支，三条叶节点共同完整覆盖树。其“多尺度同时共存”比单一 J 完整层更明确。先固定树和镜像树，不依据测试集选择。

同层小波包主要体现多频带；随 J 变化才形成不同分析尺度。不要把同层所有子带称为不同时间尺度。

### T4：多层 DWT，互补尺度控制

保留 `a_J,d_J,...,d_1` 全部分量。各分量按 P 个复系数分块，加入尺度元数据后统一至 D。边界、padding 和实际 T 同样报告。

用于判断：需要均匀细分所有频带，还是不均匀的粗细尺度已经足够。DWT 对频带的划分偏置不保证适合所有基带 I/Q 信号。

### T5：复数 STFT，多分辨率候选

先单窗，再双窗。候选窗长约 4P、8P，步长约窗长的一半；不足输入长度时缩小。使用适合重构的窗/步长组合，检查逆变换；复数 I/Q 使用双边频谱。

保留复系数而不是时频图截图。时间—频率小块展平为 token，保留时间中心、频带和窗口尺度。根据实际网格选择块大小，使 T 尽量接近基线；若为减少 T 使用有损池化，必须显式列为独立变体。

多窗输出可以先分别形成 token 再拼接，作为保留尺度的版本；另设同时间位置通道融合版本。分别计入冗余、T 和 FLOPs，不要因其信息视图多就称为“信息增加”。零填充 FFT 不等于提高实际频率分辨能力。

### T6：参数化复值滤波器组，第二阶段可选

用可调中心频率、带宽和时间支持的 Gabor/带通滤波器形成多路复响应。初始8或16路，只从验证集确定一个小配置。加上低通或残差路径是可选信息保留措施，但其成本必须计入。

先冻结滤波器验证，再开放参数学习；监控频带覆盖、重叠和塌缩。采用平方模/能量的版本仅作“相位删除”对照。此方法通常不保证完美重构，不是完整照搬 LEAF。

### T7：可学习 lifting，后续候选，不属于首轮必做

通过 `d=o-P(e), a=e+U(d)` 的预测/更新结构建立多尺度分解，逆过程使用相同确定性算子。保留两路可保证代数可逆；稳定性、频带含义及 token 嵌入后的保真度仍需检验。

只有固定表示表现出明确潜力，才投入可学习树或 lifting，避免主实验变成无边界结构搜索。

## 6. 信息保留诊断

分开报告三层，不混称“无损”：

1. 分析系数层：WPT/DWT/STFT 用已知逆变换重构，检查边界和实现。示例门限：float64 相对 L2 误差小于1e-10，float32小于1e-5；若数值条件或库实现不满足，定位原因并报告，不盲目放宽。
2. tokenizer 输出层：从 embeddings 训练小型同预算解码器恢复 I/Q，判断嵌入造成的信息瓶颈。解码器失败只说明该解码器无法恢复，不能严格证明输入不可逆。
3. 任务层：分类外，加入至少一种真实可获得标注的频偏、带宽、脉冲位置或其他物理量任务。没有对应标签时使用独立合成诊断集，不捏造真实数据标签。

重构指标：NMSE、实虚部误差、幅度谱误差；非低幅区域的相位误差可辅助报告，必须使用环形角度差并说明有效阈值。原始坐标误差为主；相位/时延对齐后的误差若提供，单列，不能用来掩盖信息删除。AWGN 样本的逐噪声重构优劣不等同于表征优劣。

## 7. 数据与泛化协议

所有方法共用原始划分。来自同一底层发射序列、长记录、设备会话或重采样源的派生样本，必须在同一划分，防止泄漏。

核心：同分布 OA、macro-F1、逐类/逐 SNR 准确率、混淆矩阵。

泛化分开定义：

- 采样率变化：用有抗混叠的规范重采样；区分固定物理时长（样本数可变）与固定 N（观察时长变化），不可混报。加入“重采样回参考采样率”简单控制。
- 符号率变化：优先通过信号生成器重新生成，不能仅修改元数据；保持调制、成形、观察时长等因素可追踪。
- 带宽变化：注明带宽由何种信号参数改变，避免同时改变多个未记录因素。
- 初相位/频偏/时移：只用于标签保持的任务；频移不得导致非预期越界混叠。真实长信号重裁剪优于人为循环移位。
- 已知 SNR 降低：按线性功率计算新增噪声；只能加到更低目标 SNR，不能用加噪把已有低 SNR 样本变成高 SNR。

数据缺少元数据时报告归一化单位；不足以支持跨采样率结论时，明确实验范围。

## 8. 分阶段执行顺序

### 阶段0：实现与基线

完成审计、统一接口、基线复现；用脉冲、复正弦、chirp和随机复序列检查频率顺序、边界、I/Q和重构。测试只覆盖这些实际风险。

### 阶段1：低成本筛选

同一筛选种子、固定训练子集和预先固定步数，运行 T0、T1、T2、T3(Haar/J2)、T3(db4/J2)、T4、T5单窗。验证集选两个前端家族，不看测试集选方法。

筛选种子建议17，后续确认种子17/42/2026；若项目有固定种子规范则沿用并记录。筛选仅判断值得继续，不作为最终统计结论。

### 阶段2：关键消融

对筛选出的候选按需执行：

- 小波包深度 J=1/2/3，完整层与固定混合深度树。
- 复系数与幅度/功率；移除某尺度/频带（保持输出形状，用零替换或预算匹配控制）。
- 元数据开关；固定与可学习前端。
- 保留各尺度 token 与先融合后 tokenize；额外 token 的原始输入控制。
- 加原始 I/Q 残差路径前后比较，并与同等 token/通道预算基线比较。

不要执行全笛卡尔积。记录选择依据和实际试验次数。

### 阶段3：确认与资源评估

T0和最多两个候选完整训练，各至少3个配对种子。报告均值、标准差和逐种子差值；3个种子不足以支持很强的统计显著性断言。

统一GPU、精度、batch和推理设置，预热后测至少100次，同步GPU计时，报告中位延迟、p95、吞吐、峰值显存；前端和主干分别计时，总延迟包含前端。比较在线计算与缓存时分别报告，不能只给候选缓存后的耗时。

### 阶段4：再接预训练

仅对监督验证有潜力的前端接回 MAE 或当前自监督协议。保持预训练数据、步数和下游微调预算一致，比较从头训练、冻结探测、全微调。

关键泄漏风险：不能先对完整原波形做重叠滤波，再只删除部分变换 token，声称对应原始区间被完全遮挡；邻近尺度和频带 token 可能已携带目标信息。

优先定义原始时间区间 mask，先遮挡输入再分析；或严格按分析支持剔除所有覆盖目标区域的可见系数。目标从未遮挡原信号计算。变换后 token 重构若采用不同可见信息量，应明确作为另一种目标，不与原始 MAE作简单等价比较。

## 9. 判断标准与停止条件

值得继续：多种子结果有一致方向，在相近成本下改善性能，或同等性能下降低成本；跨条件收益不能完全由重采样、更多 token 或普通卷积解释。

信息互补有证据：移除某一路对预期敏感任务造成特定变化，且与预算效应区分；仅画频谱/注意力图不够。

不支持假设：只有一个种子的小提升；加倍 token 后才提升且同预算基线追平；相位相关任务明显退化；实际延迟不可接受；跨采样率优势在重采样控制后消失。保留负结果，不硬凑融合模型。

若需工程门限，可预注册“候选 OA 提升至少0.5个百分点，或关键域外指标提升至少1个百分点，且成本可接受”为筛选参考；它们是建议工程值，不是科学显著性门限或项目考核指标。先依据基线波动确定最终门限，查看测试集后不得修改。

## 11. 与注意力路线的关系

本轮只用标准 Global 注意力。另见 `02_alignment_attention_experiment.md`，该路线先使用原始 I/Q token。

两者独立验证后，再考虑四组：原token/标准注意力、优选token/标准注意力、原token/优选注意力、优选token/优选注意力。当前不执行融合；跨频带、跨尺度系数不能未经时间网格和分析响应处理就直接互相关。

## 12. 参考与创新边界

- [LEAF](https://arxiv.org/abs/2101.08596)：可学习音频前端参考；其完整流程不是无损 I/Q 编码器。
- [PyWavelets 小波包](https://pywavelets.readthedocs.io/en/latest/ref/wavelet-packets.html)：分解树和重构接口。
- [SciPy ShortTimeFFT](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.ShortTimeFFT.html)：复数STFT、逆变换及可逆性。
- [Lifting 构造](https://www.mathworks.com/help/wavelet/ug/lifting-method-for-constructing-wavelets.html)：可逆预测/更新框架。

这些方法本身是既有工具。潜在贡献需要来自电磁token组织、信息互补机制和跨条件证据；本文档不是完整查新或首次性声明。
