# 扰动合理性检查（混叠/带宽）

## 方法

- 数据：RML2018A `GOLD_XYZ_OSC.0001_1024.hdf5`，24 类，SNR=30 dB 高信噪比样本（每类 ~4096 个，取 2000 个估计）。
- 复包络 `s[n]=I[n]+jQ[n]`，1024 点 FFT 得到功率谱；每类平均功率谱（按峰值归一化）。
- 两种占用带宽度量：
  1. **99% 能量紧致带宽**（可能被载波主导，低估调制带宽）；
  2. **−30 dB 带宽**（PSD > 峰值/1000 的连续区间，更贴近调制带宽）；
  3. **频带外能量占比**：|f|>0.1 / 0.2 / 0.3 的能量分数，直接检验宽频性。

## 结果

| 度量 | 结论 |
|---|---|
| −30 dB 带宽 | 全部 24 类 ≤ 0.18（多数 ±0.09，最窄 0.0） |
| 99% 能量带宽 | 数字调制类 ±0.06；AM 类（17/18/19/20）被载波主导呈 [0,0] 或 ±0.03 |
| \|f\|>0.1 能量占比 | 全部 24 类 ≤ 0.11%（即 99.89% 能量在 ±0.1 内） |
| \|f\|>0.2 / 0.3 能量占比 | 全部 ≤ 0.05% / 0.02% |

逐类关键观察（类序号 0–23）：

- 0–16、22、23：数字调制（ASK/PSK/APSK/QAM/GMSK/OQPSK），−30 dB 带宽 ≤ 0.18，能量集中在 DC 附近。
- 17、18：载波主导（AM-SSB 类），−30 dB 带宽 ≈ 0（载波尖峰）。
- 19、20：AM-DSB 类，带宽 ±0.032。
- 21：FM，谱中心偏移到 +0.031（带宽 0.030），与数据集文件名 `..._OSC`（振荡器偏移）一致。

## 结论

1. **无宽频类**：所有类别能量 99.89% 以上位于 |f| ≤ 0.1，没有任何类需要把网格强度降级为「混叠压力测试」。
2. **CFO 网格全部合法**：对 99% 能量带宽，全部类别的无混叠 CFO 范围 ≥ ±0.43 cycles/sample，远大于本轮最大 |CFO|=0.005。因此 CFO ∈ {±0.0001 … ±0.005} 的掉点**不是数据混叠伪影，而是模型对频率平移的非不变性**。
3. 类 21（FM）本身带 +0.03 的本征频偏，但不影响 ±0.005 网格的合法性（其带宽仅 0.03，仍远离 Nyquist 边界）。

> 说明：类序号对应的调制名称为 RML2018.01a 标准顺序（OOK, 4ASK, 8ASK, BPSK, …, 256QAM, AM-SSB-WC, AM-SSB-SC, AM-DSB-WC, AM-DSB-SC, FM, GMSK, OQPSK），此处仅作辅助解读，指标本身以类序号为准，未依赖名称。
