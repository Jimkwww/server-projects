# G_Q_corr 轮 errata

## 1. 可学习分支的 b 参数实际上不学习（归一化相关读出的对称性）

**现象**：`G_Q_corr` 的 8 个复数输入系数 `b_k`（16 个实标量）在整个训练过程中基本不变，梯度 ~4e-10（step2 实测），10 步后数值仍等于初始化。

**原因**：辅助分支输出 `q_k[m]` 进入 `state_corr_pack`，后者计算的是**归一化 lag-1 复自相关**（除以模平方根）。对每个通道做复缩放 `q_k -> c_k q_k` 时，分子分母同乘 `|c_k|^2`，归一化相关不变；全局相位旋转 `q_k -> e^{jφ} q_k` 同样在复自相关的相位差中消掉。而 `b_k` 的作用恰好等价于对 `q_k` 的（与信号无关的）复缩放，故 `b_k` 在读出上是冗余参数。

**结论**：`G_Q_corr` 实际可学习的滤波器参数只有 **16 个**（8 个衰减 `raw_alpha` + 8 个相位角 `theta`），16 个 `b` 停在初始化。这不是实现 bug，而是 `state_corr_pack` 读出结构固有的参数冗余。参数总数（2,254,440）不受影响；若要消除冗余，可对 `b` 加单位模约束或改用非归一化相关读出。

**影响**：报告中的 `G_Q_corr` 代表"学习 16 个动力学参数 + 冻结 16 个冗余缩放参数"的滤波器，与 `G_Q_corr_frozen`（32 个全冻结）的对照仍有效，只是"学习 vs 固定"的差异完全来自 `raw_alpha/theta`。

## 2. 历史基线统一重评估

历史基线 G / G_corr / S1 / S1_corr / Q_corr / Q_corr_frozen 的训练协议与本轮一致（normalization=none 的 order-B 增广、`augment_cfo_max=0.002`、`augment_on_raw=true`）。但历史评估覆盖的 CFO 网格不完全一致（Q_corr / Q_corr_frozen 缺 ±0.01 / ±0.02）。为保持一致，本轮对 **24 个 run（8 变体 × 3 seed）在统一的 11 条件网格上全部重新评估**，主表/差值/CFO 曲线均取自该统一重评估，而非历史存档数字。±0.01 / ±0.02 仅作扩展诊断，不计入相对下降结论。

## 3. 评估口径

- 全部评估为 **val**（train/val 划分），不用 test。
- 干净条件无 CFO 注入；CFO 条件按 order B（raw → 注入 ν → joint max_abs 归一化 → 重算 Q 特征 → 模型）执行，与训练增广顺序一致。
- 选择 best epoch 的口径：训练时按**干净 val OA 最高、同分取最早 epoch** 选 best.pt；评估直接加载 best.pt。
